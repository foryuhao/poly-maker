# 信号机制与重复性审查

日期：2026-11-11。依据为本目录SOP与所引用源码的定义核对；无策略测试、无收益比较、无候选频次估计。对应新规格M12–M16 v1.2、M17/M18 v1.1、M19/M20 v1、M21 v1.1、M22/M23 v1。目的在于明确要检验的不同信息，避免把增加条件等同于提高胜率。

最新全量复核见[M1–M23家族合并](FAMILY_CONSOLIDATION.md)：四个多分支主线合并研究入口，M11归为公共过滤器，其余机制保留。以下描述分支间的差异，不能据此把每个M编号当成独立方向证据。

## 1. M12–M23分支候选比较

M16/M17的数据门槛比较特殊，不能因状态图更短就推断成交更多。M13的旧floor和相对减损下限共同约束复验空间，不能只按“支撑恢复>=50%”估计频次。

## 2. 不是天然父子样本的几组

**M12与M14**：M12要求Ask/Bid归一化冲击比在[0.25,4]、配对确认相差<=750ms；M14要求两个Ask轮之间在[0.5,2]、Bid配对距离<=1500ms，不要求Ask/Bid比。所以M14既会拒绝只有一轮Ask的M12机会，也可能接受M12会拒绝的跨侧冲击量级。不能直接把两组差异叫“加一轮确认的收益”。

**M6与M13/M15**：M6是两轮RF与当前LW；M13/M15种子可只有一轮严格S，后来要求新SELL或BUY。共同LW身份只能做机会关联，不能保证起始样本一致。共同准入机会、各自独有机会需分开；若要隔离复验的贡献，应由测试模块另外固定同种子与同决策时点的对照，不能把种子差异藏掉。

**M4与M12/M14**：M4的“弱”是对历史参考的相对变化，允许rweak到60%；新两者上限30%。此外旧hold与新严格末尾保持不同、原执行等待也可能不同。不能将任何收益差仅归因于Ask轮数。

**M5与M17**：M5需要两个合格受击恢复轮及当前AP_SELL重叠；M17的750ms保量窗允许没有足够深的低谷，不要求AP方向份额。二者可能有交集，谁也不自动是另一方的样本子集。

**M18与M5/M16/M17**：M18的独立比较对象是冲击增长后的减损幅度。M5没有加压/损失不增门槛，但多了当前AP；M16要求时间提速，M18不要求；M17不要求有低谷及前后比较，M18需要两轮损失和恢复。不能将它们直接当作同一母样本逐项加过滤。M18的L/H改善已由成交翻倍和减损不增推出，不再算作额外独立确认。

**M19与M4/M14/M18**：M19允许Ask参考本来就弱，不要求M4的旧稳定参考；也允许参考恢复高于30%，不同于M14两轮均弱。M19的核心是同Ask的H/u至少减半而L/d至少扩大25%，每轮H>=L只排除一种量级反例，不证明逐笔成交归因。与M18比较对象分别为Ask恶化与Bid耐受，两者不是同一对轮次的竞争判定。

**M19与M4的局部包含**：固定同一对Ask轮，若A1通过M4稳定判定且`d2/d1<=10`，M19已有u比、d下限和r上限可以推出M4的Ask数值弱化式。该结论不包括轮次选择、Bid配对和等待执行，不能推出实际候选/订单子集。强参考共同区间、非稳定参考、超出M4可比范围三类应分开解释，推导见[家族合并说明](FAMILY_CONSOLIDATION.md)。

**M20与M11/M17**：M11在母候选后要求两后方档净增，M20在SELL开启时冻结三档并要求后方适度净减。只有相同档位、相同初量基准及检查时刻，其后方净变化才互斥，不能扩大到不同起点的所有候选。M17有750ms持续流及70%全程底线，M20允许早期受损，但末段需要锚档净增与后方结构；两者不是天然父子组。锚档占比上升是M20数量门槛的派生结果，不另计独立确认。

**M21与M6/M12/M14**：M21按两轮SELL分别测同一Ask净减量，且每轮前有平稳基线、root形成没有BUY@A；不要求Ask前三档总减30%，所以不保证LW成立。M6也不要求上述重复时序，两者不是父子关系。M12/M14需要Ask真实BUY受击轮，不能用M21形成窗内H=0的同Ask路径确认；其他时间/不同root的机会仍可重叠。没有BUY记录的可观测条件不能升格为撤单意图或响应因果证明。

M21 v1.1的零BUY核对须保留直接来源，不能由镜像去重后的空集确认；原始批次全部处理完才发布，晚发现的旧接收BUY在发现时结束而非当作新流量。此修订限定可用证据和阶段归属，不增加一个独立机制，也不对M6等旧规则施加隐式过滤。

**M22与M6/M12/M20/M21**：M22的Ask固定总量只允许初量±5%，若与LW使用同一集合、初始基准及检查时刻，不满足LW的30%形成损失；不同root/基准不能扩大成全市场互斥。M22不要求Ask恢复率，但有后方增量及总量限制，因此不是M12的严格子集。M20在Bid侧前聚，本版在Ask侧后聚，需旧Bid S，不是同一结构加过滤。M21在形成root观察同Ask无BUY，M22由该档BUY开启；不同窗口仍可有共同机会，不能混用一个有BUY窗口证明零BUY。

M20/M22还有共同的输入路径依赖：同一组三档端点，在不同逐项增量顺序下可能分别触发或不触发总量失效。当前v1保留原数组顺序，完整book则是一份状态；整批后发布不能代替逐项guard。这个区别见[深度批次语意](DEPTH_BATCH_SEMANTICS.md)，不能只因最终快照相同就声称两个输入或实现等价。本轮未改版本和数量规则。

**M23与M17/M20/RF**：B=100、先加50到150，后真实SELL H=30、最低与末段120的纸面路径，保留20至50%的新增缓冲但没有恢复；同一首笔初量下不满足M17末段≥135，也不满足M20受卖后净增。区别是增量先于新的卖压验证，不是已有恢复条件加过滤。不同窗口/root仍可重叠；不可称新增挂单本身被成交消耗。

## 3. 同一对轮次不能同时成立的组合

当前M10 v1要求 `H2<=0.90H1`、`u2<=0.90u1`；v2是<=0.99。M16要求 `H2>=H1`、`u2>=u1`，而合格轮H1、u1均>0。因此**同一对R1/R2不能同时提供M10与M16的形成证据**。同一市场不同时间、不同轮对仍可分别触发；不能将这个局部互斥扩大成整市场互斥。

这有助于区分两种假说：M10是冲击减弱，M16是冲击不减但响应提速。将二者直接写成“同轮同时确认的新信号”会成为不可满足条件，不为此新增编号。

实际交付的M18是独立的加压/损失幅度机制，并非上述不可行交集。M10与M18同一对轮次也互斥；M16与M18同轮H2/H1只能在恰好2的边界上同时合格，仍须满足各自其余条件。不能把不同轮对或不同时间的候选也视为互斥。

M19与M14同一对Ask轮的u2/u1范围只在恰好0.50相交，仍须各自恢复、损失、来源和时序条件；因此不能把M19简单称为M14的更严格子集。M19已有门槛推出`(L2/H2)/(L1/H1)>=2.5`，是派生量，不能另作一份确认。

## 4. M13的形成空间不能只看最小成交量

M13原floor为 `FS=QminS+0.40LS`，复验初量Q0R，uS/dS为原轮强度。给定本次初量以后，减损必须同时落在：

`[max(mR,0.25*dS*Q0R), min(Q0R-FS,4*dS*Q0R)]`。

成交必须落在：

`[max(mR,0.25*uS*Q0R), 4*uS*Q0R]`。

区间为空就没有符合本语意的复验。即使不为空，仍须真实事件、资格时点、500ms内稳定恢复和LW维护全部成立；这不是预测成功率的模型。

S从100跌到80、恢复一半到90时，旧floor88允许再降2，但比较下限要求降至少4.5，故此时没有复验空间。应记录为何不可形成，不能通过删掉旧floor或重置root偷偷增加信号。若以后研究放宽，那是不同交易语意和新版本。

M15也有独立的复验空间：LW固定集合A0、总损失L和累计BUY V须满足`V<=min(L-0.10*A0,0.75*L)`。深度尚未变化时，新增BUY的即时余量是上述右端减V；先成交后减量与先减量后成交可能有不同因果结果。详见[M15的原规则推导](M15.md)，不能把M13受击空间与M15的BUY余量合并成同一个参数。

## 5. 证据从何时开始受失效检查

| 状态 | 需要开始检查的时点 | 不允许的做法 |
|---|---|---|
| M12弱Ask等待Bid | 发布时审查弱轮窗口终点后的已知路径，随后等待配对持续维护 | 只看发布快照，或A已恢复又变薄后继续沿用原A |
| M13/M15种子 | 第一次有效LW与S重叠，固定最新合格S | 先看新冲击结果，再选最有利旧S；复用种子形成事件 |
| M14第二弱轮等待Bid | A2发布时先审查窗口后新上界，旧A1仍守至cA2，通过后A2接管 | 只守A1较宽上界、遗漏A2交接路径，或等组合后才开启检查 |
| M16第一参考轮 | 仅历史参考，无M16订单 | 把它误当M13式持续支撑，造成新复验无空间 |
| M18第一参考轮 | 仅历史数量响应，无M18订单；第二轮关闭后启用新floor | 让旧floor限制加压轮，或以L/H派生改善重复加分 |
| M19第一Ask与配对 | A1只作历史参考；A2窗口终点后的上界检查覆盖关闭和等待B，配对差严格<1500ms | 让A1上界限制A2，或A2已恢复又变薄后继续配对，或从配对重给3s |
| M20三档结构 | 形成要求固定500ms窗最后100ms，随后覆盖关闭交接和等待；P逐笔复核贯穿全程 | 用动态前三档换掉变弱价位、累计正增量、忽略中间失效或从复核清除重给TTL |
| M21重复跨侧响应 | 每轮Ask前250ms基线；R1窗口后守净减量上界，R2窗口后同时守新Bid/Ask边界 | 用缺消息当零BUY、用Ask净减量生成H=0的恢复轮、在R2形成时暗加R1 Bid floor |
| M22供给内部结构 | 旧S floor从其窗口后持续；新三Ask末100ms结构延续至关闭、发布及等待 | 只看各档不看总量、让新Ask结构给旧Bid续期、换成动态最优档或忽略批次后行失效 |
| M23先加托后验证 | 种子前及等首笔守B+80%Δ；因果处理合格首笔后才切到B+20%Δ；末段上界仅形成时适用 | 用晚来的SELL救活先前跌破、跳过首笔、用候选确认重置种子期限、把前置缓冲说成本单后方保护 |
| M17成交后数量未复核 | 每笔接收成交起算100ms，复核监控覆盖观察窗结束至发布、等待 | 用旧book/BBO冒充原档量，跳过交接阶段成交或从处理时刻重给100ms |

这些生命周期差异会影响实际可交易样本。数值门槛相同，不代表两个实现是同一版本。

本轮[交接复审](CAUSAL_HANDOFF_REVIEW.md)将M12–M16、M18分别升版，明确轮后路径按received划界、因果可得发布，以及新阶段首笔的接收与输入键双门槛。历史参考R1并未因此获得新的floor；不能把交接规则误解成所有前轮都必须持续守量。M17/M19/M20原稿已明确相应关键边界，本轮不改它们的SOP。

M16的跨越边界与M17的数量复核都必须保留明确携带锚档数量的原始事件身份；全书更新时间可能只来自BBO或其他档位。M17在未提交阶段遇到待复核成交时暂缓首次准入，但原3s寿命照常消耗；已提交阶段只允许在冻结的100ms预算内等待，不能回头把这段暴露当成已经确认的持续补给。

## 6. Maker执行下的共同反例

信号成立却排不到、信号消失前还没成交、只在取消在途时成交、信号很强但根本没有回流，这四类都可能使“候选方向有信息”无法转化为成交优势。必须保留候选→准入→订单生效→成交→结算各阶段；不能挑一个好看的阶段当作全链条通过。

多组同市场、同token、同锚价、近同时发出的模拟订单常共享一次实际机会。没有独立预算及执行规则时，不能将同一卖出流量重复算成多份可同时实现的组合成交，也不能把多个策略的相同赢家当多个独立市场证据。

固定底线与排队成交也需要共同可行的后续路径：初始厚队列若只被消耗而没有补入，会先跌破正底线，才清完本单前方队列。形成H不能抵扣尚未生效订单的队列；成交所需的入队后换手必须单独解释。物理队列与未改写历史book的反事实模拟有不同数量账本，详见[Maker可行性说明](MAKER_FEASIBILITY.md)。这是显式假设下的逻辑推导，不是对任何信号实际成交率的结论。

M20尤其需要正视这一代价：锚档增厚会同时增加前置量，其三档结构要求的联合P下限可能高于最少20%净增门槛。后方留存不能替本单清前方队列；方向观察与容易成交不是同一指标。

旧M4还存在一条应忠实复现的状态顺序：stable Ask轮可先结束旧DF，再以相对参考减弱建立新DF。r从旧参考0.80到0.55可确认弱供，后来stable的0.50可令旧弱供结束。它是源码准入/退出的不同条件，不能将M4“弱供”直接替换成新规格的r<=0.30，也不能仅凭策略别名判断同类性。

## 7. 下一步交接与新增编号原则

当前按家族优先组织研究：先承接与弱供、撤供与留托，再整理卖压承接和买攻后回流。此调整用于减少重复立项，仍不是收益排序；各分支保留清楚的版本与能力要求。测试模块后续最有用的反馈是：输入能否支持、在哪个阶段损失机会、独立成交数、信号有效期间/取消在途成交及相同口径PnL。由该反馈再决定优化方向，不继续盲目叠加条件。

暂不为M12∧M16、M13∧M15、M4+M11等纯交集新分配M编号；可以在测试模块作为显式组合/过滤版本，仍须各组件同锚、同token、当前有效，整体期限取最早原截止。只有引入新的可观测机制、状态顺序或完整成交语意，才考虑独立新SOP。此文不启动任何对照测试。

用户新增原语方向后，原语与策略层分开登记：参见[原语工具箱](PRIMITIVES.md)。QR来自M17，组合M17与QR不是新独立证据；SR记录短驻增量回落，不具备DF所需的真实受击和历史防守含义。M4的相对退出备选属于既有家族的等待分支，不新增M编号或方向机制。

M17现有显式备选`m17-qr-sr-ask-v1`「保量配短补」，引用QR v1.1与SR v1，只选择QR确认之后首个新SR_ASK。其增量是另一侧增厚的短驻路径；不是QR再确认一遍，也不等于DF/LW。因确认与执行时点改变，不能从主版已成交订单事后过滤出其收益。QR v1.1修正提取稿遗漏的发布点90%检查，主M17原定义不变；本轮没有收益或独立性实测。

新增原语[XR攻后跟挂](P_XR.md)：先有一侧真实攻击资格，再有另一侧原档净增留存，目标侧前500ms及形成期无消耗成交。与M20/QR的目标侧实际受击、M21的异侧净减不同；可以作为M23类新种子的研究入口，但其基线和确认不同，不能直接替换现有M23。若XR与SR同侧且同一增量及B/Delta，SR回落会破坏XR留存，不能同时当前有效。XR只登记原语，不新增策略家族/编号，不代表已证明统计独立。

XR接续现明确为[M23的攻后加托复验备选](M23.md)：如果XR继续当前有效，其50%底线与复验末段50%上限只交于一点；若只用50%作首笔前底线，最低初量下又没有足够空间同时满足50%损失和20%保留。显式分支保留80%前置留存，在合格首笔SELL到来时把XR转历史、切20%底线，并独立保留100ms复核。历史身份不豁免种子原始证据的迟到反证；新增当前XR不续期。该分支增加发布交接过滤和数据筛选，不能将全部行为差归因于跨侧BUY信息。

同档QR先、XR后的固定配对还存在可证明冗余：QR有效时XR基线B>=0.70Q0，XR当前F=B+0.50Delta>=1.10B>=0.77Q0，已强于QR的0.70Q0底线；两份数量守护不是两次独立承接。QR第三子窗成交及XR前500ms零成交又使cXR>cQR+300ms，所以QR原3秒截止更早。保留旧真实受卖历史和截止，合并重复guard的解释，不新增原语。XR先、QR后必须使用新受击前真实Q0R取max，不能套这个时序结论；见[组合审查](PRIMITIVE_COMPOSITION_REVIEW.md)。这些都不是实际样本包含或盈利证据。
