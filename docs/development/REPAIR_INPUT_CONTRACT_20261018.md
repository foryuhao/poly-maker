## 1. 输入分层

每轮REPAIR读取：持仓与PnL事实、市场现状和历史、当前p和sigma、时间、当前执行状态与数据质量，以及独立的策略/交易配置。

原始事实不能和模型估计混称：PnL由经济账与价格计算，p和sigma按既定市场价/波动估计口径提供；成交概率等由待校准模型估计；本轮HD/TP/SL、报价和持有期限是输出。上一轮的模式和计划则作为本轮状态输入，支持连续管理。历史排名和标准化变动由模型内部基于历史计算，不要求外部另传风险指标。

持仓、订单和行情均要携带as_of、来源与可靠性。空值/未知不等于零持仓、未成交或零波动。

YES概率p按已确认的市场价=真实条件胜率假设估计，当前实现以YES中间价为基准。原仓方向概率u在YES episode为p，在NO episode为1-p；公平概率不取整成best bid。

原始方向固定归属，当前净仓方向由实际数量计算。二者不能因最低量所迫的反向残仓混淆，进而制造来回修复。

## 3. PnL状态与模型内部计算

### 3.1 PnL与敞口

T240前、尚未Merge时：

Delta_session = Y_actual - N_actual

P_session = p * Y_actual + (1-p) * N_actual - C_session

episode使用自己的真实逐笔归因计算P_episode；按固定原始实际量归一：

m_episode = P_episode / Q0

PnL状态包括当前episode/session PnL、每原始股PnL、原仓与当前均价、浮盈峰值、回吐金额/幅度、近期不同观察时长的PnL变化。它们可由输入层维护或由模型从经济账与历史重建。前一个episode的配对利润是session账的一部分，不能直接抵消本episode的变化判断。

PnL峰值与变化采用连续可信行情及明确的成交归因，不能只用两秒一次的决策日志。部分成交、取消或新模式不能自动重置Q0、历史盈亏和真实预算。

### 3.2 价格变化与交易贡献分开

在仓位不变的区间：

Delta_P_price = Delta_position * Delta_p

仓位在区间内改变时，按事件先后用各段实际净仓累计价格影响，并单列买入成交产生的mark变化；不能把两个总PnL快照的差全部当成价格变化。

这一点尤其影响TP部分成交后转SL：减少敞口会改变PnL敏感度，买到低于公平价的资产也可能提高mark，但两者不代表持仓方向的市场概率改善；已确认退出意图不因此退回HD。

### 3.3 实际变化、波动率、历史特殊性

基础输入是当前p/sigma及可信历史。模型内部可据此计算，不作为额外风险输入要求：

- 原方向概率u在真实时长h内的有符号变化及不利幅度a_h。
- 原仓PnL中的价格贡献，不与成交贡献混用。
- 从历史读取本次变化前已知的sigma_pre，保留单位、估计窗口、样本覆盖、as_of。当前sigma继续用于描述当前市场，sigma_pre用于比较已发生变化。
- S_price = sigma_pre * sqrt(h)，以及Z = a_h / S_price。
- 事件前过去30秒同尺度变化的最大值、分布/排名和样本覆盖；历史新纪录是内部描述量，不是已确认的SL必要条件。
- 修复侧best bid的移动方向/幅度、spread变化，区分公平概率变化与仅执行报价变化。

观察尺度h与取样方式必须明确，使用真实时间，不使用“第几个窗口/消息条数”。历史对照排除本次事件，不能先让冲击抬高sigma/最大值再判断它是否异常。sigma=0、历史断档或样本不足时相关比率标记UNKNOWN，不用假分母制造信号。

30秒基线加上观察区间和事件排除需要足够历史长度，至少覆盖所选计算范围；不能把30秒稀疏决策输出等同30秒完整市场轨迹。若使用多个h，预先定义并联合验证，不事后选择最显著时长。

### 3.4 输入边界

不再要求独立的结算风险、结算盈亏概率分布、终端标准差、PnL波动风险额度/分数作为REPAIR输入。p与sigma直接保留为市场参数；实际变化相对sigma的比较仍属于模型内部计算，不重新包装成外部必需风险指标。

## 4. 执行能力与估计量

实际盘口及订单状态必需；盘口深度、成交/订单流、实际提交/取消/确认延迟分布用于提高执行估计。若缺少逐笔主动买卖方向或真实队列位置，不假装这些字段已知。

TP需要评估不同买价和等待期限下的成交机会、保留风险及转SL可能性；SL需要评估当前Maker报价的成交时间、旧订单排队价值和撤换代价。因此应积累实际POST、ACK、成交、撤单生效时间，标记ACK仅为入队时间代理。

以下只能作为模型估计/假设，并携带版本与校准状态，不能当作直接观测输入：

- 某价格在h内的成交概率、预计成交量/时间。
- 未来盘口、排队推进、价格穿越后的成交比例。
- 等待期间进入SL的概率。

旧配置中的liquidity_rate=2、queue_scale_sec=2、submit_delay_sec=0.2等是未校准假设，不是本场测得的市场事实。

## 5. 策略与交易配置单独输入

已确认边界：Buy Only、Maker Only、无费用、session15 USDC、实际Delta上限5股、现有最小数量/金额/精度、0.1股配平判断容差、T240停止新单并撤余单、之后核对与既有Merge。NORMAL保持固定。

用户已明确：整体争取正EV，但当前尚无已验证策略，先实现SL优先，不用单动作正EV或回本门槛阻塞普通SL；HD为默认。TP按episode浮动PnL/Q0 > r_TP*持有时间触发，时间从第一笔原仓实际成交起算，r_TP单位USDC/(原始share*秒)，候选由历史回放研究。买价best bid-N*tick，sigma=0.02、tick=0.01对应N=2，使用直接波动率换算，不额外引入可调报价时长。TP/SL目标配平，模式只向前，TP不回HD、SL不回TP/HD；SL允许价差内Maker。T120起停止NORMAL新开仓，T180起未完成episode强制SL，T240起停止REPAIR并按既有执行证据Merge。真实Delta超限仍优先恢复限额。

已确认执行配置：N=max(1,ceil(sigma_1s/tick))；TP首次有效挂出后固定价格长期等待；新SL直接挂对侧ask-tick；同一SL内落后至少1 tick检查追价，同价或旧价更积极时保留队列且不向下撤改。切换进入SL必须撤销旧状态余单，核对成交/真实仓位后按SL重挂，不因新单不可行而保留旧TP；已配平不再发单，仍有缺口但重挂不可行则保持SL并报告阻塞。状态切换须与同一SL内的普通复核区分。

尚待研究的配置包括路径观察尺度及SL数值边界、每秒目标r_TP候选。收益口径、计时起点、单向模式转换、执行规则及T120/T180/T240边界已确认，不再设计TP/SL回HD的恢复规则。待研究参数不是实时市场事实，也不应在没有论证时写死成0.03/share、30%或某个单场Z值。

本轮输出的TP报价、SL报价、买入数量、具体挂单期限及下一次复核时点由模型产生；上一轮已存在的目标价/期限作为连续状态读取。旧Q_BUY/Q_HOLD不是新REPAIR必须依赖的原始输入。

## 6. 数据质量是输入的一部分

每次决策需要：双侧盘口一致性/健康、连接与generation、时间对齐、价格/仓位/余额证据的新鲜度、历史覆盖时长与缺口、sigma有效性、在途事实是否解决。

行情缺失不能当价格不变，仓位读取失败不能当零，未确认撤单不能当余单消失。部分特征UNKNOWN不应伪装成确定HD或确定已完成修复；具体降级行为按执行事实和已明确的风险约束处理。
