## 持续运行方式

### M5 和 M8 实验回放

本节的 `--signal-variant` 选项控制 M5 和 M8。指定 `m5-depth-only-v1` 只对盘口深度跌幅要求两轮可比，成交冲击比仍记录为 `relative_hit_ratio`。指定 `m8-single-weak-v1` 用一轮弱化进入修复阶段，之后仍须通过两轮新修复。每个实验使用独立目录和版本身份。

```bash
.venv/bin/python ops/m511_sim_follow.py --once --source-run "$source_run" \
  --source-root "$frozen_root" --output "$new_replay_dir" \
  --min-epoch "$first_market_epoch" --max-epoch "$last_market_epoch" \
  --signal-variant m5-depth-only-v1
```

边界使用已封口的市场开盘 Unix 时间。第二个版本使用另一输出目录，并换成 `m8-single-weak-v1`。

频次实验可选 `m5-overlap-recovery-v1` 或 `m8-depth-repair-v1`。前者保留有效卖压与第二轮重叠、两轮稳定回补和第二轮恢复率至少为首轮的 80%，把成交冲击比和深度跌幅比作为诊断字段。后者在同一档位用一轮合格受击且恢复率不超过 30% 启动观察，5 秒内须完成一轮新的稳定修复，恢复率至少 60%，深度跌幅比为 0.5–2 倍。每个版本各用独立回放目录。

`m5-m8-frequency-v1` 可在一次回放中同时启用这两个版本，也可用于新身份的持续跟随模拟。持续跟随须用 `--min-epoch` 指定完整市场的开盘边界。两项策略在候选和订单审计中各自保留版本号。

### M7、M9、M10 默认规则

新运行直接使用这三个版本。M7 的衰竭观察为 500ms，两个 250ms 窗各最多为首轮买攻的 20%，合计最多 35%。允许一轮稳定承接与衰竭观察重叠，再攻必须在两项证据均可得后开始。M9 使用一轮有效期 3 秒的稳定承接与当前有效的卖压衰竭配对，再要求一轮新的同档稳定弱复验，滚动卖压须低于原冲击的 65%。M10 在首轮买攻确认后要求两轮稳定回流，第二轮的绝对卖量及归一化卖压均最多为首轮的 90%，恢复率至少为首轮的 80%。信号版本写入运行计划、候选和订单审计。既有命令中的 `m5-m7-m8-m9-m10-frequency-v1` 仍可作为 `m5-m8-frequency-v1` 的别名。

为保留现有运行连续性，新测试读取现有录制文件的追加数据，按原始 `available_mono`、输入序号和水位逐事件推进。它不新建行情订阅，也不读取未来 timer 或未来结算来生成候选。原始行情不复制、不修改。

这是**录制跟随模拟**：信号和订单时间属于源录制时钟；`status.json` 单独报告每个市场的处理水位和墙钟跟随延迟。它可以验证公共流量下的策略逻辑和模型成交，不能证明新检测器能在真实下单时延内完成决策，也不能把回放计算时间当作实时运行的通过证据。

当前测试入口是 `research_outputs/m511_sim/current.json`，包含运行目录、服务、源运行和假设成交账本。只有完成整场回放、旧 broker 快照一致、冻结代码定向测试通过后，`ops/m511_sim_start.py` 才允许启动。它保留旧服务 PID，选择下一完整市场开始，使用新运行身份，不拼接旧运行声明连续 24 小时。

服务仅能使用 Unix socket，不具备访问真实订单 HTTP 接口的网络能力。源录制终止且存在未封口成员时，新测试报告失败并保留证据。磁盘空闲低于 4 GiB 时停止新测试，不删除原始行情；未完成场次不标为完成。

## 数据质量与自有挂单

每个 token 独立证明 250ms 覆盖；PONG 和另一个 token 的更新不算。源时序、盘口一致性和完整快照有问题时记录 UNKNOWN/UNAVAILABLE，不能把它们算成“没有成交”的 EX。发生不可重建的盘口缺口后，需要完整快照恢复，不能靠下一条 delta 恢复可信状态。直接/互补镜像交易保留原身份及映射版本并去重。

已发现同一市场存在独立的 M4 实盘服务。`m511_sample_quality.py` 只读本地 M4 风险账本；若该场次有真实 POST，无法从公共聚合 L2 可靠剥离自有影响，就保守地隔离整个互补市场的主统计。完整诊断、模拟订单和成交仍保留。该筛选不进入信号生成，不用未来实盘反馈改变回放发单。统计和假设成交对照都列出 `excluded_research_samples`；不能把被隔离样本报成该策略没有信号。

此自有活动检查的范围是已知本地 M4 实盘账本，不声称能识别任意外部账户。账本无法核实时标记 UNAVAILABLE。不会为了本实验修改、撤单或查询原实盘服务的下单接口。
