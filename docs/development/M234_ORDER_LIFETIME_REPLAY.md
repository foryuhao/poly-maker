# M234 独立挂单期限回放

2026-11-08：保留原始 candidate-bound 基线，增加 3 / 10 / 30 秒挂单维护版本。
本次是离线实验，未把实验策略部署到公共行情连续模拟服务。

## 实现与可复现运行

- `ops/m1234_sim_lifetime.py`：组合原始 `M234Policy` 的入场检查和 `SimBroker`，独立管理挂单。
- `ops/m1234_sim_lifetime_replay.py`：冻结样本、并行回放、核对基线、汇总逐笔结果。
- `ops/m1234_sim_frozen_source.py`：从源运行的 `launch/source.tar.gz` 恢复并逐文件校验源码，不覆盖工作区。
- `tests/test_m1234_sim_lifetime.py`：独立数量推算及原始行情事件回放测试。

在工程根目录运行：

```bash
PYTHONPATH=src:ops .venv/bin/python ops/m1234_sim_lifetime_replay.py \
  --source-run research_outputs/m1234_sim/forward/24h-20261108T154229-66fde6 \
  --output research_outputs/analysis/m234_lifetime_20261108_v3 \
  --end-epoch 1794141000 --workers 2
```

输出目录必须为新目录。`--resume` 只复用已完成市场且要求实验实现哈希一致；中途中断的市场保留失败数据库，需新输出目录重跑，不能覆盖证据。
源运行、压缩行情 SHA256、输入序号、水位、源状态和实现哈希保存在 `manifest.json` 及逐市场 `source-state.json`。
读取原始压缩行情而非实时 API；不请求行情或真实下单接口。

## 交易意图和订单期限

原始检测器及入场资格不变。仍要求当前有效候选、合规盘口、候选观察有效、水位、maker 报价、最小数量、可用预算、T15–T240 入场窗口，每市场/策略/方向最多一次 POST。当前样本每笔预算 5 USDC。

首次 POST 建立稳定交易意图。原候选 ID 与期限另行保留，物理订单使用独立的绝对期限：首次提交时刻 + 3 / 10 / 30 秒。同方向证据刷新不改变物理订单、不恢复排队位置、不重置期限、不增加新尝试。同价位候选变化或触发组件自然消失不会直接撤单。期限从提交开始，不从首次成交开始。

独立维护规则在原录制 TIMER/POLL 上执行，不插入原录制中不存在的决策机会。到期发送撤单请求，保留原 200ms 撤单生效延迟，因此实际挂单时间可能比标称期限长一个轮询间隔加撤单延迟。原 100ms 到达延迟、FIFO 排队、部分成交和情景假设保持不变。

以下条件可以提前请求撤销剩余量，按优先级记录具体原因：

1. 订单已因行情/约束证据不足进入未决状态：`ORDER_UNCERTAIN`。
2. 行情 generation 改变：`GENERATION_CHANGED`。
3. T240 新入场窗口关闭：`NEW_ORDER_WINDOW_CLOSED`。
4. 独立绝对期限到达：`ORDER_LIFETIME_EXPIRED`。
5. 执行盘口不再通过原 `legal()` 检查：`EXECUTION_BOOK_UNAVAILABLE`。
6. best bid 跌到原入场价以下：`BID_BELOW_ENTRY_LIMIT`。盘口和公开成交在决策前已先交给原撮合器，不能在成交量消耗队列之前撤单。best bid 上升不撤单，也不追价。
7. 同策略出现触发时间更晚的相反方向候选：`NEW_OPPOSITE_SIGNAL`。
8. M4 原检测器确认 ASK 稳定恢复（原阈值 >= 0.50）：`M4_ASK_RECOVERED`。

候选消失仅记录 `SIGNAL_LIFETIME_DETACHED`，区分期限到达与其他组件/候选变化；不把笼统的 `COMPONENT_UNAVAILABLE` 自动解释成优势已经反转。原信号事件仍保存候选结束原因，执行决策另存类型化原因。

首次实现没有改价、重挂、自动追价、额外尝试或 CARA 参数学习。成交部分保留到官方结算；撤单只作用于剩余量。未决状态不会被撤单确认清除。持续公共行情模拟仍为原始基线。

## 公平对比与统计口径

同一条原始行情只重建一次信号，原始基线和六个实验撮合账户同时消费。实验账户完全独立，情景分别为 trades-only 与 cancel-half。

逐市场强制检查：

- 原始两个 broker 的完整快照哈希与原采集状态一致，包含 M1，不能只比较总数。
- 每个实验版本的 M234 候选 ID、方向、初始价格、数量和提交时刻，与对应基线逐笔一致；不一致即失败，不能继续当作挂单期限的可比实验。
- 逐笔已知结算收益与账户 payout − spent 相符。

成交率 = 至少有一次正数 MODELLED_FILL 的订单数 / 发单数。部分成交订单只计一次。未决订单单列；可以与已确认部分成交订单重叠。

结算 PnL = 已确认成交数量 ×（官方结算单价 − 入场价）。当前是毛收益，不含未经验证的手续费或返佣。未决剩余量按可能成交 0 至全部剩余量给出收益上下界，这是可行范围，不是统计置信区间。不能把已知部分 PnL 当作整个策略的确定收益。

所有版本共用在选择时已观察至 T300、VALID、已取得官方结算的市场。未取得结算、无可用快照或 INVALID 市场明确排除。部分市场没有完成 T15 前预热，`complete_window` 在清单中保留，不能宣称样本均为完整五分钟无缺口覆盖。

`comparison.json` 给出汇总；各市场 `orders.json` 可逐笔追溯。压缩原始行情保留原路径和哈希，避免重复占空间。实验 SQLite 保留完整经济事件、候选和执行决策，噪声观察器诊断只计数，`audit_retention` 明确记录保留/省略数量。

## 源版本隔离与运行恢复

本次准备回放时发现工作区 `src/polymaker/m2_store.py` 与源运行冻结版本不同；原连续服务在下一市场 INIT 抛出 `SIM_IMPLEMENTATION_VERSION_MISMATCH`。本实验未修改任何 `src/polymaker` 文件。

源版本 `4d663210c80975877bd85dda9d6c369e98dab9076f3199aca5d17eb999df8189` 已恢复到独立 runtime 目录并校验 167 个 Python 文件。旧失败运行与原行情保留，新连续运行使用独立源码和身份，绝不拼接成连续 24 小时。监控控制文件仍保留用户要求的 `enabled:false`。

恢复运行预算为 12 GiB 输出 + 4 GiB 空闲停止保护，目标仍为 288 个市场；剩余空间限制意味着不能预先保证连续 24 小时。未更改任何策略价格门槛、单笔预算或撮合经济规则。

## 本轮结果

回放目录：`research_outputs/analysis/m234_lifetime_20261108_v3`。
样本覆盖北京时间 2026-11-08 15:45 至 20:35，共 58 个已结算市场、5,928,811 条录制事件。
其中 42 个满足完整窗口标记，16 个未完成 T15 前预热；全样本及完整窗口子样本单独保留。

信号数分别为 M2 68、M3 89、M4 55；每个版本、每个情景发单数分别为 43、41、27。
原始基线及独立 3 秒版本在两个情景下均无已确认成交，已知毛 PnL 为零，但各自仍有未决订单。

| --- | --- | ---: | ---: | ---: | ---: |
| M2 | trades-only | 43 | 1 | 2.3256% | -4.7946 |
| M2 | cancel-half | 43 | 2 | 4.6512% | -3.9036 |
| M3 | trades-only | 41 | 0 | 0% | 0 |
| M3 | cancel-half | 41 | 1 | 2.4390% | +0.15960 |
| M4 | trades-only | 27 | 0 | 0% | 0 |

未决单数量如下，两个情景的计数相同，不应再跨情景加总：

| 策略 | 原始基线 | 3 秒 | 10 秒 | 30 秒 |

主要未决原因是公开成交的源时间不能可靠归属（`DIRECT_TRADE_SOURCE_TIME_UNCERTAIN`），其次是撤单生效后收到撤单前的成交（`LATE_PRE_CANCEL_TRADE`）。已知毛 PnL 不是包含这些未决剩余量的确定总收益，取值范围见 `comparison.csv`；不能据此宣布最佳期限。

三个新增成交案例均可由逐笔文件追溯：

- M3，16:40 市场：基线约 1.64 秒请求撤单，独立 3 秒约 3.01 秒撤单；10/30 秒在约 5.04 秒获得 2.660 份部分成交，`cancel-half` 已知毛收益 +0.15960。
- M2，19:05 市场：10/30 秒约 4.12 秒因 bid 跌破原限价请求撤单，约 4.31 秒在撤单生效前成交。`trades-only` 成交 79.91 份、亏损 4.7946；`cancel-half` 成交 83.33 份、亏损 4.9998。基线和 3 秒没有确认成交。
- M2，20:25 市场：10/30 秒约 9.38 秒在 `cancel-half` 成交 6.09 份、盈利 1.0962；`trades-only` 未确认成交。

完整窗口子样本保留了前两个案例，M2 的 10/30 秒已知毛 PnL 分别为 -4.7946 / -4.9998，M3 为 0 / +0.15960，M4 仍无已确认成交。20:25 案例来自预热不完整窗口。

本批样本说明独立期限能够增加成交机会，同时也能暴露不利成交；未支持 M234 统一切换到 30 秒。新增期限目前仅用于离线实验，连续采集服务仍使用原始基线。
