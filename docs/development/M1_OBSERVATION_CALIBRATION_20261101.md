# M1 观察模式参数校准

用户要求持续观察并调整参数，直到新采集的实际行情出现 `WOULD_POST`。
只读回放中的候选不能满足该目标。`config-m1` 始终保持 `observation_only = true`，
没有放开签名、资金预留或原生 POST。

## 校准方式

业务门槛集中在 `rdp_sm.m1.signal`，默认值完整保留原规格，避免修改代码常量后难以追溯。
每个信号配置保存 profile 与 SHA256 参数哈希；每场 journal、关键原始信号和 WOULD_POST 均可追溯参数。
同一场运行内参数固定，修改配置只对下一场生效。

20ms CA 容差、200ms 本地时效、500ms 源证据时效、50ms 窗口闭合处理预算没有放宽。
末段持续成交、至少两个子窗口、100ms 回补保持、EX 的 750ms 完整更新覆盖、
EX 子窗口衰减上限及 25% 总量上限保持。AP 参照窗口变长时，先按时长归一化到 750ms 的比较量，
再计算 EX，避免制造虚假衰竭。AP 窗口与回补轮次长度分别校准。交易时段仍为 T100–T240，
POST 启动预算仍为 400ms，另留至少 50ms，观察标记必须通过这些准入条件。

始终要求至少两次独立回补、至少两条进攻成交，拒绝将单轮或单条成交当作完整 M1。
参数校准是输入链路与机会可观测性的试验，不构成收益有效性结论。
