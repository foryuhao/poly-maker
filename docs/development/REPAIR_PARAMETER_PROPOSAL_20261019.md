# REPAIR 参数研究与待确认方案

日期：2026-10-19。原研究方案已由用户确认“可以，按这组参数开发”；本文件保留原始研究与确认边界，后续开发记录见[实现状态](REPAIR_HD_TP_SL_IMPLEMENTATION_20261019.md)。参数及完整规则已接入代码，运行配置和实盘就绪标记未切换。

建议首版使用：`r_TP=0.002 USDC/(原始share·秒)`；路径型SL为“2秒短窗、事前波动率1.5倍、至少2 tick的逆向变化”，**或**“每原始share的价格贡献从峰值回吐0.06 USDC”。任一触发即锁存SL，T180继续无条件强制SL。

这是一组有历史路径敏感性依据、优先SL的起始参数，不是统计识别出的收益最优解，也没有证明新策略整体EV为正。以下明确区分观察结果、研究选择和执行效果。

## 1. 历史数据实际支持什么

完整计算与数据检查见[研究证据](reviews/20261019_repair_parameter_research/evidence.json)、[结果表](reviews/20261019_repair_parameter_research/candidate_summary.csv)、[独立检查](reviews/20261019_repair_parameter_research/validation.json)。

1. 逐行读取47个市场的原始Shadow事件，共17,571,689条、21,155,061,498字节。所有原始文件在读取中计算SHA-256，保留[清单](reviews/20261019_repair_parameter_research/raw_manifest.json)。没有读test_tmp中的合成测试数据。
2. 按记录可用时间顺序恢复双侧BBO，生成T0..T300的1秒网格。只使用双侧报价可靠、同代、接收年龄不超过5秒、两侧mid互补误差不超过0.02的记录；本轮还保守排除bid=0或ask=1的端点盘口。不跨缺失段插值、不把UNKNOWN记为0。
3. 恢复记录与归档快照在同一实际时间比较：10,054个归档有效概率中，10,047个同时通过研究过滤，**这10,047个的p全部一致，差异0个**；7个未通过更严格过滤。整数秒研究网格最终有10,045个有效p、8,879个有效sigma（范围包括T300）。

6. 47市场上构造704个标准路径探针：T40、50、…、110进入，YES/NO对称，初始5 share；分别用当时公平价成本及best bid成本做敏感性分析。它们**不是固定NORMAL的实际成交，也不是704个独立市场**。另有18个较早市场的38个真实NORMAL开仓价格/本地MATCHED观察时间锚点，只作异策略补充，不作为当前策略验证。
7. 市场按时间分为前31场探索、后16场敏感性检查；重叠入场及双向探针按市场聚类。检查组仍是同一历史资料上的信号敏感性对照，不宣称完全独立的收益外测。不可靠报价或换代即右删失，报告删失，不用未来价格补齐。

研究没有假定Maker成交。对TP固定挂价，仅统计后续对侧ask下穿/触及挂价的**报价穿价机会**；它不提供队列、实际下单时延、盘口成交量或最终结算收益。不能把机会比例称为成交率。

## 2. TP：建议r_TP=0.002

保留已经确认的公式：

`m(t) = episode当前公平价浮盈 / 原始实际成交Q0`

`tau = 当前时间 - 本episode第一笔原仓实际成交时间`

`HD且tau>0且 m(t) > 0.002*tau ⇒ TP`，但所有SL条件优先。

|持有时间tau|每原始share所需浮盈（严格超过）|Q0=5时所需总浮盈|
|---|---:|---:|
|10秒|0.020|0.10 USDC|
|30秒|0.060|0.30 USDC|
|60秒|0.120|0.60 USDC|

这不是总PnL每秒0.002 USDC，而是**每原始share每秒0.002 USDC**。部分修复不改变Q0或计时起点，实际成交时点未知的历史数据只能用观察时间代理/区间，不能伪造精确成交时间。

固定SL候选（2秒、1.5、2 tick、0.06）时的TP敏感性：

|r_TP|公平价成本：47场704路径，先TP比例|后16场254路径，先TP比例|best bid成本：47场704路径，先TP比例|
|---:|---:|---:|---:|
|0.001|67.19%|67.72%|82.24%|
|**0.002**|**63.21%**|**63.78%**|**80.82%**|
|0.003|61.22%|62.60%|79.55%|
|0.005|51.42%|53.15%|55.97%|

公平价成本、r=0.002时：32.39%先SL、4.40%首次退出意图前删失，三类合计100%。TP已触发的445条探针中，53.03%在继续持有至路径SL/时间截止前有后续报价穿价机会；93%左右首张报价满足简化的首episode金额/Delta/15 USDC检查。**这些不是收益或成交验证**，且没有覆盖后续NORMAL占用session资金。

选择0.002的理由是：处于0.001–0.003信号行为相对平稳的区间，较0.001减少低效率盈利时提出TP的频率，尚未进入0.005附近明显更少TP的区间，便于用同一口径观察后续实盘/纸面数据。这个选择不能由“触发多/少”推导为EV更高；0.001、0.003保留为后续收益验证对照。

市场等权的先TP比例为62.53%，按47市场整体重抽样的95%描述区间为59.36%–65.63%。它与上表路径等权63.21%口径不同，且都不是盈利概率或EV区间。

### 必须明确的早触发行为

本批公平价成本探针中，r=0.002有42.05%在前2秒进入TP；best bid成本口径为72.87%。后者的初始浮盈含bid与mid之间的价差，且这里只是假设以bid取得仓位，不代表真实挂单一定成交。

因此，该公式会经常**很早提出价格优先的配平意图**。它不代表很快成交：TP仍按`对侧best bid - ceil(sigma/tick)*tick`，至少离bid一档，固定价格长期等候。让利润继续运行主要发生在这个等候阶段。

本研究不擅自增加最小持有时间、最小绝对盈利或扣除初始价差；这些都会改变已确认的TP语义。生产按每次有效行情变化复核，可能比1秒网格更早触发。若期望HD本身持续较久，单独调r不足以保证，需要另行修改TP条件；本次建议保持原公式，并明确接受早TP意图。

## 3. 路径型SL：完整候选规则

### A. 短窗突然恶化

设原仓方向条件胜率`u=YES?p:(1-p)`。每次有效价格变化复核，找同一连续可靠行情段内、在`t-2秒`及以前最近的历史点s，使用实际时差`h=t-s`；只在`2<=h<=3秒`时计算，防止稀疏历史把短窗变成长窗。不存在这样的点，则该分支UNKNOWN。

`a = max(0, u(s)-u(t))`

`a >= max(2*tick_held_side, 1.5*sigma(s)*sqrt(h)) ⇒ SL_SHOCK`

sigma(s)必须是s时已知的可信估计，排除事件后波动率抬升对当前冲击的稀释。使用未取整sigma；不把“1.5倍”当正态分布显著性或30秒罕见纪录。sigma已知为0时仍要求至少2 tick；sigma未知时不按0代入。

研究网格h固定2秒。生产连续事件的h可为2.1秒等，按实际h缩放；1秒统计不保证捕获全部盘中短暂跳动，需要事件级工程回放验收。

例如tick=.01、sigma_pre=.02、h=2：门槛=max(.02,.042426)=.042426；逆向.04不触发此分支，逆向.05触发。

### B. 持续恶化/盈利回吐

不能只比较当前PnL与开仓成本，不能只把负PnL视为SL。按实际成交和持仓路径分段累计**行情价格贡献**：

`L(t) = sum[Delta_episode_before_segment * (p_next-p_previous)] / Q0`

`H(t) = max(0, 历次可靠L)`；`D(t)=H(t)-L(t)`。

`D(t) >= 0.06 USDC/原始share ⇒ SL_DRAWDOWN`

L在第一笔原仓实际成交后的首个可靠价格观察处从0建立，**不从开仓成本虚构起始行情价**；若该时刻历史未覆盖，不能借成本补出缺失路径。使用episode归属的实际净仓，session的净仓另做硬限额检查。每段的Delta先由成交时间顺序确定，不把补仓造成的mark/Delta变化当成价格收益。

Q0=5、未部分修复时，这相当于**行情贡献从已见峰值回吐0.30 USDC**。它不是“当前亏损超过0.30”，不是终局最坏亏损，也不要求总PnL为负：浮盈0.80回吐到0.50也可满足。连续每秒逆向0.01、单步均未到短窗冲击门槛时，累计回吐达到0.06仍触发。

部分成交后按真实剩余Delta继续积分，不重置L、H、Q0、持有起点或模式。纯成交带来的库存/成本变化单列，不构成新的价格峰值或回撤；正向价格变化仍可抬高H，之后再度回吐按新峰值计算。

本候选的累计回吐是固定的价格贡献限度，**不会随当下sigma突然升高而自动放宽**；波动率比较由A分支承担。这样比新增可变峰值sigma/时长阈值更易审计，也符合当前SL优先。若后续收益对照支持自适应DD，再单独升级，不把本轮研究的替代规则混入首版。

### 为什么是0.06而不是0.04或0.08

以下在相同704条公平价成本探针中，假设仓位在TP之后仍未实际配平，观察首次路径SL；**不假定TP成交**。触发后的10秒指标仅针对未来10个1秒观察全部可靠者。

|累计回吐规则（同用1.5σ短窗）|路径SL触发时的持有秒数中位数|累计回吐分支先触发，占全部探针|SL后10秒回到触发前参考位|
|---|---:|---:|---:|
|固定0.04/share|7秒|51.28%|31.92%（639条后续完整）|
|**固定0.06/share**|**10秒**|**28.98%**|**28.37%（624条后续完整）**|
|固定0.08/share|12秒|14.77%|27.14%（619条后续完整）|
|自适应max(.04,3*sigma_peak*sqrt(1秒))|12秒|15.91%|26.74%（632条后续完整）|

0.06是在候选中取中间的风险取舍：0.04更快但回弹代价更明显，0.08让累计恶化分支明显更晚/更少承担退出。自适应门槛亦有价值，但此资料不足以用EV区分其优劣，本轮不为2秒差异增加新锚定参数。

推荐组合下89.49%的探针最终出现路径SL，路径SL持有秒数中位数10秒；若都未配平，48.15%在前10秒已触发。后16场的路径SL比例为96.06%、触发持有中位数仍10秒。**这是偏积极的止损策略，不是只捕捉极少数异常。**

触发后10秒有76.92%的完整后续路径还会再恶化至少0.01；同时28.37%会回到参考位，两者可以同时发生，不能相加，也不能据此判断做SL一定赚钱。A用冲击前u作为参考位，B用当时价格贡献峰值对应的u作为参考位；本批不模拟部分仓位变化，因此该对应存在。

单独只用1.5σ短窗也有87.64%的探针最终触发，持有中位数13秒。此市场上绝对2秒变化/sigma_pre/sqrt(2)的P90=1.78、P95=2.33（6,459个有效窗口）；反复观测1.5σ不等于某个低概率的episode误报保证。

## 4. 优先级、降级和执行边界

按以下顺序，每次有效行情/成交更新复核；T180/T240有独立时间事件，不等待新的市场消息：

1. T>=240：停止新REPAIR、撤余单、核对迟到成交，满足证据屏障后Merge。
2. 已满足严格小于0.1 share的完成标准，且已处理旧单/未知在途：结束episode；只在T120前允许下一NORMAL。
3. 已锁存SL；或可信实际session `abs(Y-N)>5`；或T>=180；或A；或B：进入/继续SL。
4. 已处TP：保持TP，不能回HD。
5. HD满足第2节收益速度条件：进入TP。
6. 其余HD。

A或B任一即可，不要求同时成立、先亏损、破开仓价、创30秒记录或旧Q模型BUY优势为正。若同一事件同时满足TP和SL，SL优先。SL不可解除，直到episode完成或截止。

行情断代、价格不可靠时，不跨缺失区间计算A或虚构连续的L增量；保留先前退出意图与累计证据，暂停相关不可确定分支并记录HISTORY_UNKNOWN。若有完整成交事件账本及两个可信端点、能排除中间仓位变化的不确定性，可单列核对净mark变化；它不能充当这次断档内的2秒冲击证据。

恢复后标注PARTIAL_PATH，在新可靠连续段从局部L=0、H=0计算局部回吐，不将缺失部分当零贡献拼接到旧L。**局部回吐达到0.06仍可触发B**：真实全episode峰值回吐至少不小于该可靠段内已见的回吐，因此这是充分证据。局部回吐未到0.06不能据此宣称全episode未超阈值；旧峰值/缺失段仍保留未知标记，只有完整行情及成交账本恢复后才能重建精确全路径。新段价格贡献核算本身仍需可靠仓位和成交事件。A的可靠短窗可在累计两秒可靠历史后恢复；sigma另需满足自身预热。

sigma缺失只使依赖它的A/新TP报价不可确定。若价格贡献路径和成交账本完整，B不额外依赖当前sigma，仍可触发；这需要在现有实验实现中去除B对当下sigma的无关门槛。T180/真实Delta硬限额也不依赖sigma。仓位/订单事实不可靠时，不新增POST，先核对。

进入SL时按已确认规则撤旧状态余单、核对实际/迟到成交，再以对侧**最新ask-tick**重新挂Maker。原单同价也做状态交接；同一SL内只有旧买价落后最新ask-tick至少1 tick才追价，其他情况保留队列。TP固定价等待期间也持续监测A/B；到T180无条件转SL。预算/最小单/Delta不可行时记录SL+EXECUTION_BLOCKED，不恢复HD/TP、不违规加量。

## 6. 请求确认与后续验收

本轮请确认的具体方案是：

- `r_TP=0.002`，保留当前浮盈/原始share/实际持有秒数口径，接受可能很早进入TP意图，不新增冷却期。
- 短窗SL：目标2秒，实际基准年龄2–3秒，`a>=max(2tick,1.5*sigma_pre*sqrt(h))`。
- 累计SL：完整可核算的episode价格贡献峰值回吐`>=0.06/share`，无需PnL转负；固定阈值，不随当前sigma升高放宽；部分成交按实际Delta积分。
- A/B任一锁存SL，保留已确认的优先级、T180/T240及执行规则。

用户确认后才修改策略参数/实现。仍需事件级路径、部分成交与断档恢复、TP→SL撤单重挂、未知在途、预算及截止边界验收。当前研究**没有补齐长挂Maker反事实成交、完整新策略session最终收益、进程崩溃后自动续跑等所有实盘条件**；不会据此设REPLAY_VALIDATED或切换实盘配置。若用户确认的是参数设计，不等于授权伪造已验证收益/就绪状态。
