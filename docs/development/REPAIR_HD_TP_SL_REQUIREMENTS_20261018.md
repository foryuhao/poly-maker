# REPAIR：HD / TP / SL 最新确认需求

日期：2026-10-18。状态：策略与执行需求已确认，新hd_tp_sl_v1开发版已实现；参数校准和完整实盘验收未完成。详见[开发状态](REPAIR_HD_TP_SL_IMPLEMENTATION_20261018.md)。

当前详细方案见[REPAIR_HD_TP_SL_PLAN_20261018.md](REPAIR_HD_TP_SL_PLAN_20261018.md)，输入见[REPAIR_INPUT_CONTRACT_20261018.md](REPAIR_INPUT_CONTRACT_20261018.md)。本版覆盖此前“SL可恢复”“报价仅best bid”“普通SL负EV权限待定”“TP必须先有方向转弱”等冲突建议。

## 1. 三个出口

|模式|触发/意图|操作|
|---|---|---|
|HD/HOLD|默认；尚无TP或SL触发|持有，不新增修复单，记录路径并复核|
|TP|收益 > 每秒收益目标 × 持有时间；价格优先|对侧BUY，best bid - N*tick，N由波动率决定，争取配平|
|SL|路径恶化、真实Delta超限或T180强制规则；时间优先|允许价差内积极Maker，持续争取配平，不再回TP/HD|

SL优先于TP。当前策略还没有被验证为正EV，先实现SL；不再用旧BUY/HOLD的微小EV比较阻塞SL。成本保留核算用途，但不要求退出回本或获利。普通SL允许必要收益让步，不覆盖资金、Delta、Buy Only、Maker Only和截止边界。不能由这些规则宣称正EV。

## 2. 路径与输入

模式由路径决定，而非只按当前PnL符号或p/sigma状态决定。保留短时变化、累计恶化、盈利回吐、变化前sigma及真实观察时间。异常、累计与回吐判据不要求同时满足；具体数值待回放确定。不能重新默认固定0.03/share、30%回吐或必须刷新30秒纪录。

输入为真实持仓/成本、episode/session PnL与历史、当前条件概率p与sigma、双侧盘口/深度/tick、时间、执行事实和数据可靠性。不另输入结算风险、波动风险分数。公平概率不改成best bid。

## 3. TP细则仍需参数化

明确采用用户的每秒收益触发，未另加方向转弱条件。已确认收益用episode当前浮动PnL/Q0、时间从第一笔原仓实际成交起算，目标单位USDC/(原始share*秒)。每秒目标r_TP由历史回放给出候选，通过完整session最终收益比较，不把浮盈目标的命中率当作正EV证明。

确认买价best_bid-N*tick，使用sigma直接换算：sigma=0.02、tick=0.01对应N=2。已确认N=max(1,ceil(sigma_1s/tick))，向上取整且至少1 tick；sigma_1s使用现有sigma固定1秒变动尺度，数值直接使用当前sigma，不再引入k或可调报价参考时长。订单复核独立于波动尺度，不假定成交概率。

已确认TP不回HD：收益跌回目标线以下仍继续争取配平；路径恶化则升级SL。模式路径为HD->SL或HD->TP->SL，TP也可成交后直接完成episode，不必先转SL。TP首次有效挂出后固定价格，不随bid/sigma周期性撤挂；等待至实际完成、SL或必须处理的执行/硬约束变化，不能通过订单超时解除退出意图。

## 4. SL锁存与Maker边界

本episode进入SL后不可回TP、HD，不因反弹、历史缺失或重启解除。新SL直接挂对侧最新ask-tick，仍须低于当前ask并通过post-only，不先best bid再逐档提高。一档价差时ask-tick等于best bid。

同一SL状态内，已有买价落后最新ask-tick至少1 tick时检查追价；同价或旧价更积极则保留队列，不为便宜价格向下撤改。

状态切换进入SL时，无论此前状态，一律撤销旧状态未成交单，核对实际成交/迟到成交与仓位后按SL规则重新挂；即使旧TP价等于新SL价也不直接KEEP交接。用户不接受因新SL不可行而保留旧TP的例外。未知POST/撤单先核对，不能并行重复敞口；已配平则不再下单，仍有缺口但预算或最小量导致重挂不可行时，保持SL并输出阻塞原因。状态切换强制重挂不等于已在SL内每次复核重挂。

## 5. 配平与NORMAL

TP/SL目标配平，仅T120前可进入下一轮NORMAL loop；不再主动优化保留仓位比例。实际数量、严格小于0.1股容差、最低量所迫反向尾仓的归属与不往返修复规则继续有效。实际尾差仍计入session账。

进入下一轮前必须满足既定完成条件，且旧订单不存在未解决的重复成交风险。部分成交不重置原始Q0、持有时间或预算；发单不等于完成。

## 6. 时间与数据降级

时间规则已确认：T120起不允许NORMAL新开仓，只允许REPAIR；T180起未完成episode强制SL；T240起停止新REPAIR、撤单核对并按既有关闭屏障/持仓证据开始Merge。配平后T120以上等待收尾，不再开下一轮NORMAL。T180时间触发不依赖sigma暖机或新的行情消息。

T240停止新REPAIR并请求撤余单，继续核对迟到成交；之后Merge不参与前面的决策。

历史/sigma不足时不虚构路径型信号；既有退出计划尤其SL锁存不自动消失。限额恢复和时间型SL不依赖虚构历史，仍要求执行事实可靠。关键事实不可靠时停止新增并核对。
