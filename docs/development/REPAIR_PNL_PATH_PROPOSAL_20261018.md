# REPAIR：以 PnL 路径决定退出，以 Maker 执行降低敞口

日期：2026-10-18。状态：新方案提案，未接入交易代码，参数未校准。

最新需求澄清：本文保留为历史候选设计，其固定保护线参数、异常三项AND、统一退出锁存及默认配平等未获用户确认。当前HD/TP/SL的需求与执行语义以[REPAIR_HD_TP_SL_REQUIREMENTS_20261018.md](REPAIR_HD_TP_SL_REQUIREMENTS_20261018.md)为准；本文不能被当作当前已定开发契约。

用户最新目标是“截断亏损，让利润跑”。本方案替换旧 review_lease_v2 作为风险退出决策器的职责；旧 Q 只能保留为研究与执行诊断。它不再决定已经触发的风险退出是否可以继续等待。

## 1. 目标和边界

固定 NORMAL 信号、报价及其已有执行边界，只重新设计 REPAIR。

- 第一层根据当前持仓的 PnL 路径，决定是否继续保留方向敞口。
- 第二层完成已触发的风险退出，在可行 Maker 方案中考虑成交、排队、价格和延迟。
- 正 EV 由 NORMAL + REPAIR 的完整 session 最终结果检验，不要求每一次退出都提高增量 EV。
- Buy Only、Maker Only，无手续费；不增加虚构费用。买入后可能发生的负增量 EV 不是手续费。
- session 连续预算 15 USDC，包含真实已花费、活动订单和未决执行预留。
- session 实际 Delta = Y_actual - N_actual，固定 |Delta| <= 5 share。真实超限优先恢复；不可行时报告剩余超额，不能假装已恢复。
- T240 停止新 REPAIR POST，撤销余单并核对迟到成交。T240 后才能进行既有 Merge，Merge 不进入前面的风险模型。
- 严格小于 0.1 股沿用已有配平判断；真实尾差仍进入资金、仓位和 session Delta。
- 实际经济成交及实际仓位优先，MATCHED 不必等待一定出现 CONFIRMED；不以超时猜测成交。

政策变化必须显式版本化：旧政策仅在真实 Delta 超限时允许必要的负增量 EV 修复；本提案扩展为，明确的亏损/盈利回吐/异常逆向变化退出触发后也允许。资金、Maker、Delta、最小量和截止边界保持约束。

0.01 USDC 的 BUY 优势门槛尚未确认，本方案不启用；更不把它作为风险退出的准入条件。

## 2. 两套账和 PnL 口径

session 经济账用于预算、真实风险、最终表现：

P_session(t) = p(t) Y(t) + (1-p(t)) N(t) - C_session(t)

此式用于 T240 前尚未 Merge 的阶段。Merge 后按既有现金/库存账核算，不能重复计算兑付。

风险退出跟踪当前 opening episode，不能用前一笔已锁定利润掩盖本笔恶化。记录：

- Q0：本 episode 原始实际开仓数量，旧开仓余量可靠结束后冻结。
- C0：该批原始实际开仓的成本。
- u(t)：原持仓方向的条件胜率；原仓 YES 时为 p，NO 时为 1-p。
- P_episode：本 episode 的完整逐笔经济盈亏归因。

在尚未开始 REPAIR、原仓数量固定时：

m(t) = P_episode(t) / Q0 = u(t) - C0 / Q0

m 的单位是 USDC/原始 share；不是“每股当前残仓”，不随部分修复缩小分母。Q0=0 不进入风险持有状态。

同一 episode 的历史峰值、触发状态、原始量和风险参考线不因两秒复核、修复部分成交或重启恢复而重置。迟到原仓事实需要可靠重建归因，不能拼接不一致历史；未解决时阻止新风险提交。

历史成本在这里用于定义止损政策的参考点，这是本提案明确采用的风险偏好。成本不变成 Maker 回本价限制，也不要求修复后 PnL 为正。原来的“仅改变历史成本绝不改变动作”不再适用于这层以 PnL 为参考的风险政策。

## 3. 用保护线决定何时退出

本版先使用可解释的规则，不把 PnL、波动标准差、结算风险线性相加成一个分数。

### 3.1 参数候选

以下只是用于研究与算例的种子值，未获生产参数确认，也没有历史统计校准结论：

|参数|候选值|含义|
|---|---:|---|
|b_loss|0.03 USDC/原始 share|允许的浮亏参考；m <= -b_loss 请求退出|
|b_arm|0.04 USDC/原始 share|达到此峰值后开启浮盈跟踪保护|
|rho|0.30|浮盈峰值允许回吐的比例|
|n_tick|2|最小噪声容忍距离，以实际价格 tick 计|
|k_noise|1|短期波动噪声倍数|
|h_noise|2 秒|固定的噪声观察尺度，不是订单 TTL，也不等于保证完成修复的时间|
|a_min|待校准|异常退出的最小实际逆向变化，按 tick/每原始股计|
|z_exit|待校准|异常退出所需的波动倍数，不直接取某一笔观测值|
|h_shock|待选择|实际变化与历史对照共用的观察尺度；不随CPU复核耗时改变|

b_loss 是参考触发预算，不是最终亏损保证；5 股的 0.03/share 对应触发参考 0.15 USDC。不能把它理解为每次复核重新允许再亏 0.15。

### 3.2 保护线

仅在 RUN 状态，以可信行情更新：

H(t) = max(H(t-), m(t), 0)

初始保护线 F = -b_loss。峰值尚未达到 b_arm 时，只使用这条亏损线。

达到 b_arm 后，开启并持续保持跟踪保护。噪声容忍距离：

A(t) = max(n_tick * tick, k_noise * sigma_pre * sqrt(h_noise), rho * H(t))

原始跟踪线：

F_raw(t) = H(t) - A(t)

实际保护线：

F(t) = max(F(t-), -b_loss, F_raw(t))

退出条件：

m(t) <= F(t)

sigma_pre 使用本次逆向变化之前已经可用的估计；不使用未来数据。它的作用是噪声容忍与执行状态判断，不是预测价格必然反转。

保护线只提高、不降低。因此新波动升高不能自动放松已经建立的亏损/回吐保护。短期 sigma 估计异常或缺失时，不能将其置零；保留已有保护线，不因数据缺失扩大持有权限。价格本身不可信时按执行健康规则暂停新单，不能依据旧价制造退出成交。

高水位应使用连续可信行情，不只看每两秒输出。微小浮盈要达到 b_arm 才激活跟踪保护，tick 与噪声下限用于控制普通报价跳动导致的过度退出。

### 3.3 波动异常与结算风险分工

实际变化与历史波动率共同进入风险退出，而不只作日志或执行节奏提示。它们度量不同的东西，保留独立字段，不合成没有明确含义的加权分数。

在 RUN、原仓数量固定时，定义实际观察间隔 h 下的逆向变化：

A_h(t) = max(0, m(t-h)-m(t))

它等于该区间每原始股的 PnL 恶化幅度，也等于原持仓方向胜率的下降。数量变化时须剥离成交贡献，不能把仓位/现金变动当成价格波动；第一版已经进入 REPAIR_ACTIVE 后不重新触发/解除退出。

与变化发生前的波动率比较：

S_h = sigma(t-h) * sqrt(h)

Z_h = A_h / S_h

sigma=0 或样本不足时不除零，标记不可估计并记录绝对变化。h 取可信观察时间，不把“每平方根秒的 sigma”直接与任意时长跌幅比较。

再与事件开始前过去 30 秒的同尺度实际逆向变化比较：

B_h = max{ A_h(s) : s <= t-h，且该历史比较区间位于指定的过去30秒基线内 }

E_h = (A_h(t) > B_h)

E_h 表示相对已观测同尺度历史的新纪录。历史样本必须排除本次事件，不能在当前冲击先进入均值/最大值以后再判断它是否异常。可另记录经验排名，但重叠窗口的排名不是独立样本显著性或已知尾部概率。

“Z=1.64”与“30秒内未出现过”没有逻辑等价关系。前者是相对均方波动尺度的幅度，后者需要真实历史最大值。即使暂用正态作为参照，单侧1.64倍约为5%尾部，也不能推出它一定是短窗纪录。

新的候选异常退出条件为：

SHOCK_EXIT = (A_h >= a_min) AND (Z_h >= z_exit) AND E_h

总体退出条件扩展为：

EXIT = (m <= F) OR SHOCK_EXIT OR 实际Delta超限

a_min 用实际 tick/每原始股 PnL 表达，防止极低 sigma 把一档噪声放大成强信号；z_exit 是风险退出灵敏度，不是凭单场确定的统计显著性门槛。两者均待样本外校准。固定 h 或预先列明的多尺度候选也须事先确定；多尺度联合使用须整体验证误触发，不能事后挑一个最显著区间。

连续价格采样应按真实时间对齐，不能以行情消息条数或CPU复核窗口计数代替。重连、缺帧、跨代际或历史覆盖不足时 E_h=UNKNOWN，不当作新纪录或假定没有异常；已有保护线和可靠的亏损/回吐退出仍然生效。

异常但尚未满足全部退出条件时，进入高优先级复核，保存A/S/Z/历史最大值与样本覆盖，不放松已建立的保护线。满足 SHOCK_EXIT 时，即使尚未碰到原浮亏/回吐线，也锁存 REPAIR_ACTIVE；不要求PnL已经转负。

异常退出是风险控制政策，不自动给价格过程添加“随后必然继续下跌”的预测。短/长波动率差和盘口变化继续用于判断成交模型是否失效，以及执行紧迫程度。

结算时的 session PnL 只有两种结果：YES 赢时 Y-C，NO 赢时 N-C，概率分别为 p 与 1-p。单列报告下行结果及概率，不与短期波动相加。本版不私自新增“最终亏损概率必须低于多少”的硬阈值。

## 4. 状态机

|状态|意义|转换|
|---|---|---|
|RUN|允许原方向敞口继续持有|亏损线/回吐线、异常逆向变化触发，或真实 Delta 超限 -> REPAIR_ACTIVE|
|REPAIR_ACTIVE|已决定降低原方向敞口|可靠配平 -> PAIRED；最低量所迫反向残仓 -> RESIDUE_HOLD；T240 -> CUTOFF|
|PAIRED|按已有容差配平且余单、迟到执行已可靠解决|按旧规则结束 episode，必要时允许后续 NORMAL|
|RESIDUE_HOLD|最低金额/数量所迫的合法反向尾仓|保持原 episode 来源，不往返买回原侧制造震荡|
|CUTOFF|T240 后不再新增 REPAIR|撤单、核对、Merge/结算、恢复路径|

T240 优先于新修复，即使仍有风险或真实超限，也不能突破截止条件发新单；记录未解决风险。

首版 REPAIR_ACTIVE 是锁存状态：短暂反弹不自动回 RUN，不重新使用旧 Q_HOLD 阻止退出。这样避免修复意图随每次行情来回切换；代价是触发后可能错过 V 型反弹。自动解除退出如需支持，必须另行定义滞回规则并验证，本版不包含。

NORMAL 原余单仍可能成交时，不并发提交对侧修复。沿用已有原单收尾、迟到成交、经济事实和资金预留规则，不靠计划数量提前假定原仓已经冻结。

## 5. 执行层：稳定的退出意图与可变的报价

退出意图与单张报价分离。

repair_intent 持久化 episode、触发原因、触发时间、m/H/F、Q0、目标净敞口和风险版本。普通行情变化不撤销这个意图。

quote 表示在某一最新有效盘口下，可提交的价格、数量、订单身份和绝对期限。旧 quote 不适用时更新报价，不重新争论是否退出。

新单价格 = 对侧真实 best bid，且必须满足 post-only。数量以 session 真实净仓及所有未决执行影响计算，尽量配平；只有 venue 最低量/最低金额所迫才允许越过配平点。若资金或最大量只允许部分改善，选择合法部分量；连最小合法单都不可行时报告 BLOCKED，不违反预算或 Delta。

所有实际数量、最低金额、0.01 股精度、session 15 USDC、|Delta|<=5、在途预留与账户证据守卫继续生效。未知成交或旧单可能继续成交时，先解决事实再替换，不能重复买入。

执行链路：

1. 进入市场时预热 SDK/tick 等约束，失效时刷新，避免 BUY 后重复串行查询。
2. 可信行情更新 m/H/F，触发计算为常数级算术，不等待秒级 Q 求解。
3. 触发后读取最新盘口和经济事实，准备报价、签名及必要的提交前持久化。
4. REPAIR 不等待额外一条行情才激活。
5. 发送前检查意图仍有效、最新 best bid、Maker、数量、资金、tick、行情代际、未决执行与 T240；不再要求双侧 BBO 指纹逐项完全不变。
6. 未提交时若报价过期，合并最新行情并更新 quote；已可能提交则先核对该订单，不直接重发。

不同于旧方案，新状态复验不需要重新计算 BUY/HOLD Q。方向退出意图已经由保护线锁存，最新盘口只决定具体如何合法执行。这直接减少此前“模型返回后已过时，又在准备阶段继续等待”的问题。

### 5.1 保留队列与重新报价

常规业务复核保留约 2 秒；在保护线触发、明显逆向移动及成交事实变化时立即唤醒。活动单不因每次复核自动撤单。

研究初值可用 5 秒作为未成交订单的复查期限，不是无条件 5 秒撤单。仍接近 best bid 的合法原单优先考虑保留队列；落后最新 best bid 两档及以上时优先核对撤换。强烈恶化时缩短复核，不改成 Taker。

每次延期必须是明确决策并记录绝对 cancel_at，不能暗中滚动 TTL。撤后重挂先解决原余量及迟到成交，排队年龄重新计；不以“预期已成交”减少真实风险。

以上 5 秒、两档是执行研究参数，不是已确认或校准的最终值。只有实际接受及实际成交才代表订单进入队列和敞口下降。

Maker Only 不能保证在保护线价格或时间内成交。未成交期间风险仍在；临近 T240 必须报告尚未修复数量，不能把请求退出写成已截断亏损。

## 6. 旧 Q 与数值修正的位置

- 已确认的网格规则保留：以真实当前公平价为锚，状态步长 0.01；当前与未来共用锚点和报价构造，不把 p=0.635 取整为 0.63/0.64，不扩大原盘口价差。
- 旧 review_lease_v2 只作对照与诊断，不作为已触发退出的阻断器。
- 可另研究给定退出意图下的队列保留、撤换和成交时长模型；其目标是完成受约束的修复，不重建“现在买与两秒后买”的风险退出准入。
- 数值精度、成交概率和实际延迟仍要验证；网格修正不证明真实 EV。

## 7. 第 10 -> 11 次决策的算例

只用已提供的决策采样，假设尚未更早触发/成交；取该采样前的峰值 H=0.145。它不是逐 tick 闭环回放，不能据此声称真实首个触发点一定是第 11 次。

原仓 YES 5 股，总成本 2.65，均价 0.53。

|量|第 10 次|第 11 次|
|---|---:|---:|
|时间|T67.413|T70.050|
|YES 胜率|0.675|0.625|
|NO bid/ask|0.32/0.33|0.37/0.38|
|总浮动 PnL|0.725|0.475|
|每股 m|0.145|0.095|
|每股峰值 H|0.145|0.145|

使用上面的候选参数，以及第 10 次已知 sigma=0.018754：

- rho H = 0.0435；两档下限 0.02；sigma sqrt(2) = 0.0265228。
- A = max(0.0435, 0.02, 0.0265228) = 0.0435。
- F = 0.145 - 0.0435 = 0.1015，折算原始 5 股为总 PnL 参考线 0.5075。
- 第 10 次 m=0.145 > F，继续 RUN。
- 第 11 次 m=0.095 < F，锁存 REPAIR_ACTIVE，原因 PROFIT_DRAWDOWN。
- 若提交前仍为同一盘口且约束可行，候选为 BUY NO 5@0.37；无需先证明其旧 Q 比 HOLD 高出多少。

若立即全部成交，配对 PnL 为 5-2.65-1.85=0.50，已经低于 0.5075 的触发参考。这说明采样跳变和 Maker 延迟会穿越参考线；0.5075 不是可保证的最终盈亏。

以上种子值只用于展示决策机制，不以“第11次必须触发”倒推最优参数。后续真实回放必须使用连续行情、实际延迟及可能改变之后仓位的成交，不能逐行独立生成事后交易。

本例的窗口端点相隔2.636608839秒，实际逆向变化0.05，先前sigma=0.0187544767，因此S=0.0304528402、Z=1.64188298。它可以被政策定义为值得响应的逆向变化，但“过去30秒未出现”须另查同尺度历史最大值。

现有前10次决策采样里，最大相邻逆向变化0.03，最大绝对变化0.04；观察跨度约24.134秒且间隔不一致，不能据此宣称已验证完整30秒的同尺度新纪录。现有periodic snapshots主要保存账户/同步证据，没有完整每秒概率序列供这个结论复核，E_h应保留UNKNOWN。风险层应补充原始概率样本与样本覆盖日志。原亏损/回吐分支不因此失效。

待实现/验证：连续 PnL 高水位与保护线持久化、锁存退出意图、事件驱动快速提交、执行延迟统计、可靠的成交/队列回放、参数样本外选择。没有历史撮合队列数据时，限价触及不能直接当作全部成交；使用保守/基准/乐观成交假设并报告敏感性。

比较至少四组：固定 NORMAL 不修复、旧 REPAIR、仅亏损退出、新的亏损+浮盈跟踪退出。使用相同 markets、原始开仓、行情可见性和预算，之后让各组完整闭环运行。

报告：session 最终平均 PnL 及区间、亏损尾部、浮盈回吐、触发到 POST/实际成交延迟、T240 剩余 Delta、过度撤换、强制反向尾仓、资金占用。胜率单列，不作主目标。

参数按时间划分训练/验证/留出，不能在本场挑阈值再用本场证明有效。若收益不确定性不能支持正 EV，应保留研究/影子模式，不把“止损规则直观正确”当成收益证明。

## 9. 研究依据及适用范围

本方案是针对当前二元市场和已确认交易边界的工程提案，不是文献中已经验证的本市场策略。

- Avellaneda & Stoikov, *High-frequency trading in a limit order book* (2008)：区分库存风险偏好和订单成交机制，再选择报价。这里只借鉴风险与执行分层，不照搬其双边做市、效用函数或参数。https://math.nyu.edu/inmemoriam/avellaneda/HighFrequencyTrading.pdf
- Kaminski & Lo, *When do stop-loss rules stop losses?* (2014)：止损规则的收益贡献依赖底层收益过程，不能从止损机制本身推出正 EV。本策略须在固定 NORMAL 下验证实际 session 结果。https://www.sciencedirect.com/science/article/pii/S138641811300030X
- NIST, *Cumulative Distribution Function of the Standard Normal Distribution*：1.64倍的单侧正态参考尾部约5%；这是分布参照，不是最近30秒是否创造纪录的证明，也不证明本市场收益正态。https://www.itl.nist.gov/div898/handbook/eda/section3/eda3671.htm
