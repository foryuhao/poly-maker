## 发现及对模型的影响

|检查|结果|影响与处理|
|---|---|---|
|同期数据连接|47场Shadow与固定NORMAL的12场重合为0；旧日志对齐19场|高：不同日期不拼成同一路径。旧组仅作辅助约束|
|行情有效性|14,100槽位均有记录，但有效p只有10,054条，约71.3%；541条标记MISSED|高：有行不等于有有效行情。缺口保留，使用actual_snapshot_time做as-of，禁止按计划时间提前读取|
|撮合时间|31场合计133笔确认成交；387条状态事件中的native ts均无有效正值；18,820次官方trade重复观察中match_time/timestamp也无有效正值|高：不能把首次本地MATCHED时的p当作撮合公平价。重复观察不是独立成交样本|
|固定NORMAL组修复|80次真实提交，14张单有确认成交，共20笔修复成交；另有1条未发送记录|保留全部提交与零成交，不只挑成功配平单；14/80是该历史政策的描述性成交比例，不是每秒强度|
|固定NORMAL组撤单时机|70张修复单有撤单请求，距本地POST起点中位1.039秒，最大3.007秒；另10张已提交单没有撤单请求观察|高：没有有意保留20/40/140秒的样本支持。没有撤单记录不能解释为无限续挂；与成交/终态逐单核对|
|旧组挂单与规模|86个修复报价提交结果，其中66个有订单身份；这66个首撤请求年龄约3秒，数量6至9.1股|高：不能把旧组当作当前5股、15USDC策略。部分旧市场累计NORMAL成本达16.73USDC|
|成交观察延迟|旧组100笔成交全部在撤单请求后才首次本地观察为MATCHED；固定组33笔中28笔如此|高：这是“晚观察”，不证明物理撮合全部发生在撤单之后，也不测量交易所撤单失效概率|
|旧版批量返回|36条REJECTED报价没有订单ID，其中16条共享的raw batch同时含其他成功腿|高：逐报价身份处理，不能把整批均判作失败或均判作成功。已核对所有确认成交都能关联有身份订单|
|最终赢家|31场run_result均为UNKNOWN|高：不能算相对持有到结算的单一已实现收益，也不能用最后中价充当实际结算|

以上是该范围内直接观察，置信度高；把这些观察推广到新政策的成交/收益关系仍缺少证据。所有Shadow摘要报告dropped events、writer errors为0且writer drained；这不抵消行情无效或快照缺失。133个成交身份均最终CONFIRMED，本次没有FAILED标签供失败概率拟合。

固定组POST客户端RTT：209次，p50=0.238秒、p90=0.593秒；DELETE请求RTT：1,080次，p50=0.222秒、p90=0.363秒。后者含同一订单的重试/重复撤单，不是1,080张独立订单。业务cancel ACK计时口径另为200次，p50=0.239秒、p90=0.535秒。三者均不是物理入队/撤销生效延迟，不能用其中位数替换演示模型的固定0.2秒后就宣称已校准。

## 不需要撮合时间也能先做的收益研究

对一张已解决执行事实的BUY订单，令X为最终确认成交量、b为买价、Z_side为该侧最终兑付指标，则其相对相同原持仓不再交易的最终增量为：

`G = X * (Z_side - b)`。

多次成交/不同价格用逐笔求和。没有成交且已可靠解决余量的订单记G=0；未解决订单保留未知，不记0。这个标签不需要知道每笔准确撮合秒数，因此可以作为直接学习`E[G | 下单前状态, 动作/后续规则]`的路线。Z_side只用作事后标签，绝不能作为当时决策输入。

这仍有两个边界：最终赢家当前缺失；历史只执行短TTL政策，不能用短TTL收益标签直接评价未执行的长挂单或不同撤换规则。动态后续订单必须整体归因，同一市场相关订单不当成独立收益试验。没有动作覆盖时，换一个拟合方法也不能产生真实反事实标签。

本次还计算了无需猜赢家的经济结果区间：固定组将所有NORMAL与REBALANCE确认买入完整计费后，12场最终总PnL落在 **[-7.2102, -7.1902] USDC**，差额来自0.02股残仓。不计手续费、返佣或其他成本。公式为每场`Y_total*Z+N_total*(1-Z)-C_total`，Y/N使用累计经济买入，含Merge兑付的经济等价表示，不把Merge后物理库存与全历史成本混算。

这个区间是本批历史路径结果，**不是EV估计**。其中`min(Y_total,N_total)-C_total`已扣残仓成本，不能直接当作旧复盘中不含残仓成本的“配对利润”。该组REBALANCE相对相同原开仓HOLD的增量，因缺赢家只能给出宽区间[-28.2602, 16.7598] USDC，不能据实际总PnL为负就断言每次REPAIR均降低EV。正常开仓的每场累计成本最高8.70USDC，但此会计对照没有宣称完整替代政策的执行/资金路径已经验证。

## 对方案的具体更新

1. **模型参数继续标注未校准。** lambda0、队列年龄效应、报价距离衰减、穿价深度和长挂单流动性衰减目前只用于情景分析；不选择能制造正EV的一组参数作为答案。
2. **优先补终局标签，再研究直接收益。** 使用权威结算与token映射补齐Z，不从末价推断。本次尝试读取首场官方Gamma市场接口，网页读取不可用，直接只读请求返回HTTP403；没有获得结果，也没有把未知改成输或赢。无需用户手工整理日志。
3. **执行模型用时间区间和观测过程。** 有本地POST起点时，以它到首次MATCHED/CONFIRMED作为保守撮合区间；旧版仅有placement intent时标记更宽的下界。不能默认某次缓存“未成交”观察是新鲜、可靠的撮合下界。
4. **把长挂单支持列为实证缺口。** 在未取得支持前，可以输出模型推演的BUY/KEEP/CANCEL及计划期限，但必须同时给参数敏感性、数据支持范围与研究状态；不包装成实盘已证实方案。本次不擅自启动交易来补样本。
5. **两条路线分别验证。** 短TTL已有动作可先研究订单/episode终端收益标签；长TTL与连续复核仍需结构模型、区间识别、样本外闭环检验，无法从旧单价格触及直接生成成交。
