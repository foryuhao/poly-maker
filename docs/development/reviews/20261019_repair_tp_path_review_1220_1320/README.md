# TP逐轮兑现分析：12:20–13:20固定12场

2026-10-19，Asia/Shanghai。范围沿用上一轮锁定的12个已完成市场，14轮实际REPAIR，9轮先TP、5轮直接SL。0.01股dust轮不计入分母。本次只分析历史，没有修改交易代码、参数、配置或正在运行的订单；此前已实现的2.5股规则不被倒灌到旧市场。

## 结论

先TP的9轮最终配对部分合计 **−0.87390492 USDC**，其中4轮TP成交合计+1.29902852，5轮TP→SL合计−2.17293344；另外5轮直接SL合计−5.40。首张TP实际报价有2轮配对收益≤0。9轮首次TP账面浮盈合计0.59524268、平均0.06613808，首次补仓成交被本地观察到之前，原始腿已记录浮盈峰值平均0.24996585；6/9轮的峰值小于配置允许的0.06 USDC/原始股累计回吐。

这批的收益缺口同时发生在三个层面：小利润对应较大的回吐预算、TP状态与实际报价盈利含义脱节、SL触发后的行情及成交差额。首张报价定得更远、等待更久，没有稳定换来足够大的已实现收益。

## 口径

1. 原始腿浮盈 `Q0×p_held−原始实际成交成本`，p使用策略记录的YES mid或其互补值。Q0为最终实际开仓数量固定投影，不是期间每一毫秒的账户实际仓位曲线。
2. 峰值取首次TP历史条件点之后、首笔补仓MATCHED被本地观察到之前，**已记录**行情的最大估值。缺少原生撮合时间，观察成交前的最后一小段也可能已实际成交，尤其12:40峰值与MATCHED观察相隔约5毫秒，不能当作可抢到的价格。
3. TP历史条件点、控制器实际检测、POST分开列。历史回放识别不等于当时已能下单。官方elapsed通过同一次observe当前点或活动批次POST时钟锚点映射到本地T；表中T取近似到0.1秒，不称交易所精确时间。
4. 报价配对收益按实际原始成本和限价计算，只算配对数量；余下的反向仓位成本、风险和结算另列。报价本身不是成交，mid峰值也不是成交保证。Maker配对收益可能超过已记录mid浮盈，例如13:15第二轮。
5. 全部实际经济成交按trade_id与maker_order_id去重，最终均CONFIRMED，实际配对PnL与前次Merge重算结果一致。原始12份JSONL的SHA256逐份核实未变。

## 收益结构的三个可量化缺口

### 1. 回吐预算与可见利润尺度不匹配

正常5股配置的累计回吐额度为0.06×5=0.30 USDC；9轮中6轮的TP后已记录峰值低于各自的额度。以12:25①为例，峰值+0.225，允许回吐0.30，触发时已−0.075。12:45①峰值+0.075，触发时已−0.225。

这是累计回吐分支的含义，独立的短窗异常波动可更早触发；可靠路径中断又可能使累计分支更晚。因此不能将0.30理解为保证能守住的单轮亏损上限。

### 2. 五轮TP→SL的大部分差额在两个阶段产生

| 诊断阶段 | 配对前原始腿估值/实际配对收益 |
|---|---:|
| 每轮已记录峰值相加 | +0.85074980 |
| SL历史条件点估值相加 | −0.78985004 |
| 最终实际配对PnL相加 | −2.17293344 |

峰值→SL条件点差额 **1.64059984**，SL条件点→实际配对差额 **1.38308340**，合计3.02368324。前者主要体现退出条件允许的回吐与路径可靠性，后者包含旧单撤换、准入、Maker等待、价格变化及估值/成交价差，不能全当成代码延迟。这些差额是诊断基准，不是可保证恢复的利润。

### 3. 单纯“让首张TP都成交”也不覆盖当时的直接SL篮子

把这9张已实际提交的首张TP报价固定，假设配对部分全部按该报价成交，算术收益合计 **+2.22346156**，仍小于观察到的5轮直接SL亏损5.40，差 **3.17653844**。

这是固定已发生轮次和报价的金额对照，**不是反事实策略回测**：没有模拟提前成交后的新NORMAL，没有假定真实能成交，也没有纳入反向尾仓结算。它说明当前首张TP报价所表达的收益规模，本来就低于这批SL损失规模；不能将所有问题都归因于没成交。

## 对后续设计的含义

- 先明确“发TP单”的当前经济条件，避免TP标签对应负配对收益或零收益；历史曾达到TP条件不能替代当前报价检查。此处涉及暂缓的RP-001，当前仅分析。
- TP利润保护应与已经出现的利润尺度相联系。固定0.06/股回吐额度在小利润轮次中很容易允许从盈利转亏；需要研究利润留存和回吐预算，而非直接把本批峰值当成可成交止盈目标。
- TP报价距离需同时考虑当前浮盈、剩余可获利润和成交等待风险，不能只由sigma决定。在有限上行空间中，追加0.10收益是否值得承担0.30回吐，需要明确代价。
- 直接SL平均−1.08仍需要控制。改善TP利润留存与减少少数大额SL损失需共同评估；固定NORMAL的前提保持，本次没有重新设计入场。
