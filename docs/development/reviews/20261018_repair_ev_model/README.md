## 2. 第一个可计算的模型

这是一张订单加结算持有的受限候选模型，借鉴公平价格扩散和报价相关成交强度的建模思路，不直接套用论文结论：

- Avellaneda & Stoikov：[原文](https://math.nyu.edu/inmemoriam/avellaneda/HighFrequencyTrading.pdf)。
- Feil & Nendel，预测市场随机控制：[原文](https://arxiv.org/html/2607.17991v1)。

### 2.1 公平价格

价格位于0至1、0.01间距的格点；0和1吸收。在每个dt内，向上/向下一格的概率各为 `sigma^2*dt/(2*tick^2)`，其余概率不变。自动缩短dt以保持概率合法。内部格点的条件均值不变、局部方差率等于输入sigma平方；因此符合本轮“价格是真条件胜率”的假设。

sigma在一次候选预测期内固定，是模型简化；不是已经验证的长周期波动预测。无活动订单的固定仓位持有价值为当前M。

### 2.2 示例盘口及成交

演示盘口明确设为公平价两侧各0.01，因此p=0.31时，NO bid/ask=0.68/0.70。**这不声称真实NO bid等于1-p-0.01。**接真实行情时需要用真实盘口替换该假设及相应校验。

新单按此best bid提交。假设提交延迟0.2秒，到达时若已满足可立即成交条件，post-only拒绝，不记作成交。

活动单的每步流动性成交概率为 `1-exp(-lambda*dt)`，每次成交一股或最后不足一股的余量。其中：

`lambda=lambda0*(1-exp(-age/queue_scale))*exp(-kappa*(fair_value-b-half_spread))`。

- 示例lambda0=2/秒，表示一股成交事件的基础强度，不是“整张5股单2秒成交”。
- queue_scale=2秒，表示新单排队初期成交较慢；保留原单沿用年龄，重挂需要重新排队。
- kappa=50/价格单位，表示价格变远时更不易成交。
- 当示例市场ask穿到原限价或以下，假设余量全成交于原限价，允许相对公平价产生负收益；这是待验证的深度/执行假设，不把真实日志触价直接归属为实际成交。
- 申请撤单后继续承受0.2秒的成交风险，再停止；T240发起撤单并不代表没有迟到成交。

这些成交参数均未从真实数据拟合。示例只证明“给定明确的模型能计算订单”，不能据此挑选有利参数并宣布策略正EV。

### 2.3 候选与求值

新单在不超过现有缺口的范围内，搜索最低合法数量、整股网格、合法的精确缺口和向内取整的最大数量。只有最低股数/金额迫使超量时，才加入该最小超量候选；不为赚取模型价差主动扩大为反向新仓。所有候选遵守15 USDC及原开仓量方向敞口限制。这不是对全部0.01份额网格的连续最优证明。当前5股缺口恰好等于最低股数，因而合法数量候选只有5股；数量选择仍由约束导出。

挂单期限候选为2/5/10/20/40/80/120/140秒，按到T240的剩余时间裁剪。它们是研究网格，不是已确认生产参数。

对每个候选传播价格、部分成交数量和剩余概率质量，完整计算最终二元兑付的均值与二阶矩。撤单后的残仓继续持有至结算；充分配平或post-only拒绝后不再假设额外交易。按期望PnL选择，期望相同时比较终端风险。

对已有订单，单订单基线比较KEEP与CANCEL_NOW，后者包含撤单在途成交；输出 `advantage_vs_baseline` 明确比较基线，`incremental_ev`保留相对当前M的会计分解。[第二轮](CONTINUATION.md)已加入一次撤旧后重发的条件序列；新单和旧单仍不被拼成瞬间撤换。

这是明确的受限rollout模型，不是全局最优Bellman控制器。未来复核后可重算，但这一重规划策略的完整EV还需要另外回放验证。

## 4. 真正连续的T100→T102情景

先假定T100的NO5@0.68已经post-only接受，订单仍按原价存在；模型中的排队年龄到T102为1.8秒。

- p=0.25，若尚未成交：KEEP NO5@0.68，研究网格中的计划撤单仍是T240；KEEP策略EV约-0.1263。它保留较低买价和队列位置，不因新best bid变为0.74就自动追价。
- p=0.30，若尚未成交：KEEP NO5@0.68至计划T240撤单；KEEP策略EV约0.0575，不自动改到0.69。
- p=0.35：在本模型的连续格点路径及穿价全量执行假设下，已接受的旧单会在此之前穿价成交。若确实全量成交，库存YES5/NO5，锁定PnL为 `5-1.50-5*0.68=0.10`，不再下修复单。

如果旧单在到达时已被post-only拒绝，就适用无活动单的重新决策，不假装已有成交。p=0.25或0.30也可能先穿价成交再回落，因此终点价格本身不能替代订单事实。

部分成交同样使用已有余单计算。例如NO已成交1股后，原单余4股可继续有效，不按新订单最低5股强制重挂。完整输出包含已成交0/1/3股时的KEEP计算；其他成交量需按实际事实输入。

## 5. 模型真的会改变动作

保持T100、p=0.31、原仓和资金不变：

- lambda0=2、sigma=0.02：BUY，最优示例增量EV约0.0187。
- lambda0=0.5、sigma=0.02：候选订单全部负增量EV，选择HOLD。
- lambda0=2、sigma=0.03：该候选族全部负增量EV，选择HOLD。
- lambda0=5、sigma=0.03：仍能选择正增量EV的买单，具体最优量/期限见JSON。

波动升高并不自动要求买更多或更快。风险随价格影响成交与终端结果，再通过候选EV体现。实际参数存在不确定性时，应报告跨参数情景的动作是否稳定；当前示例在未知成交强度上不稳健，不能发真实订单。
