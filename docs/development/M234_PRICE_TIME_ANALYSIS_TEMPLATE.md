- 同方向限笔跳过的研究信号保留在有效根信号库存。M2 使用 `all_candidates`，M3 按 CA 根，M4 按 DF 根。
- 价格分十桶，边界为 `[0.0,0.1)` 至 `[0.9,1.0)`，合法价格满足 `0<p<1`。
- 时间以开场后经过秒数计，每三十秒一桶，从 `[0,30)` 至 `[270,300)`。当前开仓窗口为第 15–240 秒，空桶明确显示零笔及无适用收益。
- 同时输出价格桶、时间桶和价格×时间交叉桶。
- 单笔风险上限 5 USDC，每策略/规则每场额度 20 USDC，每场每方向至多一笔假设成交。
- PnL 为官方兑付减去开仓成本，ROI 为总 PnL 除以已结算总成本。未知结果保持待结算。
- 保留零信号市场的覆盖数量。每个桶单列独立市场数，各桶独立市场数允许重叠。

## 固定分析结构

1. 写明快照时间、累计策略范围、覆盖市场数量、开仓窗口及模拟成交假设；来源版本保留在依据中。
2. 总览分别列出三策略的已结算笔数、独立交易市场、PnL、ROI 和待结算数量。
3. 价格十桶对照表采用“已结算笔数 / PnL（USDC）”。
4. 开场后三十秒分桶对照表采用同一格式。
5. 价格×时间交叉分桶采用文字与表格解读，冻结 JSON 保留全部交叉桶。
6. 稳定性列出共同时间中点之前与之后的 PnL、最佳与最差单场、去掉最佳单场后的 PnL。
7. 解读收益集中度、价格结构与时间结构的关系，指出交叉桶样本稀疏和全胜/全负样本。
8. 附来源与计算依据，并报告实际影响三策略的公共依赖版本差异和输入质量限制。

市场聚类 bootstrap 为固定随机种子的 20,000 次抽样，按整场汇总后重新计算 ROI。
仅在至少三十个已结算交易市场且同时出现盈利方向胜负结果时记录探索区间。
全胜/全负样本的区间留空。区间及各桶排名受多重比较和反复查看影响。
三十场只作为区间计算的探索下限，正式交易规则需另行冻结并使用后续样本验证。

`full_window` 描述观察窗口覆盖。输入连续性另按事件核对，计划关闭产生的 `GAP` 与非计划断流分开统计。
仅影响看板的代码差异按巡检既有作用域排除，实际公共行情和结算依赖的变化保留告警。

## 运行

在项目目录运行一次即可生成当前版本的新分析。

```bash
.venv/bin/python -B ops/m234_price_time_analysis.py
```

重现某次已冻结分析的呈现，使用该次 JSON。

```bash
.venv/bin/python -B ops/m234_price_time_analysis.py \
  --from-snapshot research_outputs/m2_virtual/analysis/m234_price_time_20261106.json
```

`--version` 接受完整的 64 位冻结版本号。`--output` 可指定一个尚不存在的输出目录。
`--min-price 0.20` 对既有记录作包含边界的分析筛选，保留原有方向限笔后的成交状态。
报告同时记录筛选条件、筛选前数据和筛选范围内的待结算数量。

```bash
.venv/bin/python -B ops/m234_price_time_analysis.py \
  --from-snapshot research_outputs/m2_virtual/analysis/m234_price_time_20261106.json \
  --min-price 0.20
```

默认每次写入 `research_outputs/m2_virtual/analysis/price_time_runs/<时间>-<版本>-<标识>/`。
每次生成 `analysis.json`、`summary.md` 及最后发布的 `manifest.json`。
清单记录模板编号、数据快照时间、采集版本、生成时间和各文件 SHA-256。

定期复核时先读取清单及数据快照，按固定结构给出发现与限制。
会话报告直接使用文字与 Markdown 表格，计算依据随冻结 JSON 保存。
