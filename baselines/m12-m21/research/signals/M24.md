# M24 哪边在补

**交易语意。** 同一短窗里，原买一 P 真实受卖，原卖一 A 真实受买。按可见数量与直接成交推算，买档有正净补给，在补给股数及每股受击得到的补给上均领先卖档。此后只要该优势仍可证明，在固定原买价 P 成交，观察至官方结算。卖档可以同时净补。v1 是独立策略假说；阈值和时间是首版设计取值。

## 1. 输入、起点和计量范围

- 按 [COMMON](COMMON.md) 使用市场/token、generation、tick、Decimal 数量、完整盘口、原始批次、去重、质量和双时钟。UP/DOWN 分别建状态。只继承这些数据规则，所需的两侧材料性见下节。BA、AA、RF、QR、DF、LW、AP 以及跨档实吃均无需先确认。
- 空闲时，首笔命中事件前买一的直接 SELL，或命中事件前卖一的直接 BUY，启动唯一观察。两侧谁先均可。冻结该笔之前的同一完整盘口，取原买一 P、原卖一 A 和正股数 B0、A0。首笔也计入。若两笔属同一已证明的原子批次，共用批次前态，按来源键定唯一 root。缺失前态或归属不清记 UNKNOWN，不用成交后盘口反推起点。
- 令首笔接收时刻为 t0，e=t0+500ms；形成统计窗为 [t0,e)，同接收时刻只计首笔键起的合法记录。root 身份取 (version,market,token,generation,P,A,首笔来源键)，输入按 (available,input_seq,subindex) 处理。固定价位和侧别，始终只计打向 P 的去重直接 SELL 股数 HB 和打向 A 的去重直接 BUY 股数 HA。其他价位、互补 token 镜像及自有执行不贡献独立证据。原档可留在同侧非最优位置；任一档明确撤空、消失或重建即结束，不能换用新买一、卖一。价格仅定位队列。
- 每个累计终点需有两侧原档数量 QB、QA 及同范围直接成交的完整来源。形成首笔前的数量必须已可得；终点要能证明原档报量已包含计入该侧的最后一笔成交，且未纳入窗外变化。可用有因果依据的原子帧，或源序明确的同档后续报量和完整水位；同一个毫秒、全书更新时间、别档更新及解析器默认方向均不足以证明。多笔成交可由一份覆盖它们的末态核对，无需每笔都额外等一次回报。只有事后才能取得的记录不能回填确认。能力不足记 UNKNOWN/UNAVAILABLE。[输入能力](INPUT_CAPABILITIES.md) · [深度批次边界](DEPTH_BATCH_SEMANTICS.md)

## 2. 确认计算

每侧真实受击须达到本侧门槛 `HB ≥ max(0.5,0.0001×B0)`、`HA ≥ max(0.5,0.0001×A0)`，股数等号通过。需要双侧真实成交，但不要求先卖后买、多笔分桶、已见低谷、深度损失达标、两侧成交量相近或稳定保持。250ms 桶仅用于核对输入覆盖。

| 量 | 含义 |
|---|---|
| JB = QB − B0 + HB | 在可对齐的公开队列上，将已知消耗加回深度净变化，得到买档可见净补给的估算。 |
| JA = QA − A0 + HA | 同口径的卖档估算。正、零、负分别表示净补给、净额持平、净撤出。 |
| JB/HB、JA/HA | 每股已观察到的受击对应多少股净补给。允许负数及超过 1，不截断。公开 L2 无法分拆期间各笔挂入、撤出或参与者身份。 |

在同一完整边界须同时满足 **JB > 0、JB > JA、JB×HA > JA×HB**。采用精确十进制交叉相乘；严格等号不确认。第一项排除两侧都退、买方只是退得少；第二项保证买档净补给股数领先；第三项排除仅因买档承受更多卖量所造成的股数领先。三项是同一个比较的限制，共用一份证据。各侧相对于初始深度的比例、优势幅度及 Ask 净补/零/净撤分组只作诊断。

e 到达且完整水位已覆盖形成窗时，在首个合法批末按可得时刻 c 发布，`e ≤ c ≤ e+50ms`。先检查窗内末态，再依次处理从 e 到实际发布边界的已知失效和维护条件。窗外成交只进入维护；不得用它补足初始 HB/HA 或修复未通过的形成。e 到 c 有反证或无法证明连续通过时不发布。原截止固定为 d=e+3000ms，有效区间 [c,d)。

## 3. 等待、失效与重新开始

1. 发布后仍从同一 t0 累计 HB、HA，冻结 B0/A0/P/A。每个可证明的完整边界都用最新 QB/QA 和同步累计量重算同一组谓词。普通新 BUY/SELL 本身不直接否决或续期；买档净补给降至零、股数领先消失、单位受击补给领先消失，任一即永久结束该 root。**刚好持平即结束**。后来补回不能复活旧信号。
2. 一次已知原子行情批处理完整后判断；有独立先后证据的多个边界必须顺序处理，首次已证失效不能被后一帧恢复遮盖。两侧无相关变化时沿用已证状态，但须保持来源与覆盖。如果新成交和同档报量尚待核对，在首个受影响的已完成输入边界转为待复核，停止新准入并对已挂余量请求撤单。以首次出现缺口的 available 时刻起最多 50ms，后来的未决输入不重置时钟；这不是增加形成时间。只有在此上限前（严格小于）能证明中间每个独立边界均满足条件才可恢复引用。不能只用最终合格末态解释整个区间。已提交过的订单不重挂；从未提交过的意向，仅在原期限内恢复可引用后才可首次准入。待复核期间的成交按当时可证状态单列，事后核对不改写当时的可得性。
3. 原档丢失、换代、tick 变化、盘口非法或明确的来源断裂立即结束。可核对等待超时、顺序无法重建、必需范围内的直接成交缺失为 UNKNOWN；已知数值失败另记 FAIL。d 等号先到期，同一边界先处理失效，再看执行。发现迟到反证时保留发现时刻、原归属和已有执行，不能撤销历史成交。
4. 每 market/token/版本仅一个形成或有效 root。等待、待复核和执行回报均不延长 d。失败、到期或未知结束后，只用接收时刻及可得键都晚于结束边界的首笔全新合格成交另起；不重用结束帧内的成交，不滑动窗口挑一对好端点。每个 root 最多发布一次。

## 4. 固定锚价执行与结算问题

| 执行方式 | v1 语意 |
|---|---|
| Maker | 信号可引用且允许在原 P 合法被动挂买时等待后续回流。形成时的 HB 不抵扣自己的排队量。失效或进入待复核即撤未成交余量；部分、在途及失效后成交分别保留。 |
| Taker | 仅在可引用时有同 token、同 P 的真实可取卖量才可主动买。正常未交叉盘口且原 Bid P 保持正量时，这一准入受限。记录执行不可行；禁止换价、换 token 或借原档消失取得同价成交。 |

遵循[固定锚价合同](FIXED_ANCHOR_CONTRACT.md)，信号计数独立于能否发单。价格带、队列模型、费用、市场剩余时间、订单余量及预算属于执行配置。自有挂量/成交若影响原始深度或消耗量，需能隔离；无法隔离时记录证据受污染，不能用自己的成交维持信号。

待验证的问题是：同锚价、同剩余时间、相近两侧初始深度和主动买卖量、同执行口径下，双侧都受击时，买方净补给领先的那些**有效原价成交**是否更常最终胜出。保留同窗卖方也在补的记录，区分“Bid 补得更多”和“Ask 在撤”。买方补给强也可能让 Maker 排不到，后来能成交的可能发生在支撑转弱时。假设全额、已证成交、未决和官方结算分别记录。

|---|---|
| [M12 买卖恢复差](V_M12_VALIDITY_OVERLAP.md) | M12 比较两次合格受击后相对各自低谷的恢复率，并要求买档末段保持。M24 从窗前数量和实际消耗推算净补给，两侧都可以高恢复，甚至没有可见低谷。M12 也可能在 M24 的卖方单位补给更强时成立，见下表。 |

| [M4](M4.md)、[M5](V_M5_RELATIVE_RECOVERY_DIAGNOSTIC.md)、[M6](M6.md)、[M18](V_M18_STABLE_RECOVERY.md) | 分别要求 Ask 相对既往冲击衰退、持续卖压与两轮 Bid 稳接、Ask 多档疑似退量与两轮 Bid 承接、同一 Bid 前后两轮耐压比较。M24 只取一次双侧核算。上述策略各自也无同时满足本版两侧补给领先的要求。 |

**统计重叠需要保留。** 同档同窗内，JB−JA 恒等于双侧深度变化之差再加 HB−HA，不能把这些字段算成多份独立利多。若某侧可见损失 L 恰等于 H，且 Qend 未超过初量，则该侧 J/H 恰等于低谷恢复率。这类窗口与 M12 的恢复信息高度重叠；对等初量、成交量、端点和路径，原始信息可以完全复算。M24 的独立之处是选择不同盘口过程，尚无独立结算优势证据。交接时按同 market/token/P 和有效区间是否重叠标记同根/异根来源；同场不能直接视为重复成交。

## 6. 定义算例与最小输出

以下均为纸面算例。除表中指出的条件外，假定两档初量各 100 股、数值和来源可证、原档连续存在、无先前进攻/轮次或预加托。

| 形成或维护证据 | v1 判定 |
|---|---|
| HB=HA=20，QB=98，QA=94，两侧低谷均为 80，各侧仅一笔直接成交 | JB=18、JA=14，单位补给 0.90 对 0.70，M24 成立。Ask 恢复 70%，M12 的弱 Ask 条件失败；M21 有 BUY，M17 缺三段 SELL，M23 缺预加托。 |
| HB=10、HA=40；Bid 低谷 90、末量 95 并满足 M12 的末 100ms 保持，Ask 低谷 95、末量 96；两侧组件及各自守卫仍有效 | M12 的恢复率 50% 对 20%，Ask 损失 5%，归一化冲击比 4，可合法配对。M24 的 JB=5、JA=36，单位补给 0.50 对 0.90，拒绝。 |
| HB=30、HA=2，两档末量均为 100 | JB=30、JA=2，但两侧单位补给均为 1，拒绝。若只有 Bid 受卖，HA=0 时直接在材料性检查处结束。 |
| HB=2、HA=30，QB=100、QA=85 | 单位补给 1 对 0.50，但 JB=2 小于 JA=15，拒绝。极小买档受击的高比例不能掩盖卖方实际补回更多股数。 |
| HB=HA=20，QB=75、QA=60 | JB=−5、JA=−20，相对差为 +15 仍拒绝。 |
| 从首行已确认状态起，无新成交，原 A 经有序改量从 94 到 98，再回到 94 | 初次达到 98 时 JA=JB=18 即结束；末态不复活。若同时间戳来源无法证明中间状态，按批次合同与质量分支处理，不任挑顺序。 |
| 实际发布 c=e+50ms / 晚于 e+50ms；当前可得时刻恰为 d | 前者在其他条件均合格时可发布，超时记 UNKNOWN；到 d 已过期。迟到的双侧末量不能延后开始新的 3s。 |
